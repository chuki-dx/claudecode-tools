サイトの目的

中小企業の情シス・社内SE が、Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)を社内で安全に試し、配り、予算を説明できるようにすることを目的としています。ブラウザだけで動く無料ツールと、その背景を説明する解説記事を掲載しています。

ツールに入力した内容は外部に送らず、ブラウザの中で処理します。

閲覧数の記録

どのページがどれだけ読まれているかを知るため、ページを開くと、次の内容だけを運営者のサーバ(jpexam.ai-income.jp)に送ります。外部のアクセス解析サービスは使っていません。

  • 開いたページの URL(パスのみ)
  • このサイトに来る直前に見ていた別のサイトのドメイン名(検索エンジンなど。ページの URL は送りません)

Cookie は使わず、ブラウザに何も保存しません。ツールに入力した内容は送りません。ブラウザでトラッキング拒否(Do Not Track・Global Privacy Control)を有効にしている場合は送りません。

送信先のサーバには、通常のアクセスログ(IP アドレス・日時・ブラウザの種類など)が記録されます。通常のアクセスログは障害の調査と不正アクセスへの対応に使い、容量の上限に達すると古いものから消えます。閲覧数を数えるための記録には、IP アドレスの末尾を伏せた値(IPv4 は最後の数字を0にした値)だけを残し、14日で消します。集計して残すのは、日ごとの閲覧数・訪問者数と、ページ別・参照元のドメイン別の閲覧数だけです。広告には使いません。

掲載内容の確認方法

  • 製品の仕様や料金は、執筆時点の公式ドキュメント・公式ページで確認し、参照したページへのリンクと確認した時期を記載しています。
  • 実機で確かめた内容は、確かめた環境(OS と Claude Code のバージョン)と時期を記載し、公式ドキュメントで確認しただけの内容と区別しています。
  • 誤りに気づいた場合は、確認のうえ修正します。

免責事項

本サイトの情報とツールの出力は、執筆時点で確認した範囲のものです。Claude Code の仕様や料金は変わることがあります。利用の前に公式ドキュメントで最新の情報を確認し、社内に配る場合は手元の環境で動作を確かめてください。本サイトの情報やツールの利用によって生じた損害について、運営者は責任を負いかねます。

本サイトは Anthropic 社の公式サイトではなく、同社とは関係のない個別の運営者が作成しています。

アフィリエイト(広告)の方針

本サイトはアフィリエイトプログラムに参加する場合があり、その場合は該当箇所に PR と表示します。

紹介する商品やサービスは、記事の内容に関係があるものに限ります。広告の有無によって、記事の評価や記載内容を変えることはありません。

本サイトには、運営者が販売している有料の記事・本(note、Zenn)へのリンクがあります。これらは「有料記事」「有料の本」と価格を併記して表示しています(一覧: 本・有料記事の選び方)。運営者自身の商品のため PR の表示はしていませんが、アフィリエイトのリンクとは区別して載せています。
