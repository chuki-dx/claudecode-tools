Claude Code API 料金 見積もり計算機

Claude Code を API の従量課金で使ったときの月額を、人数・1日あたりのトークン数・稼働日数・モデルから計算します。入力した内容はブラウザの外に送りません。

条件を入れる

1人1日あたりのトークン数

入力例は、有料記事で使った架空のログ(1人・5日分)の Sonnet 5.5 の合計を5で割った値です。実在の人や部署の数字ではありません。

5分・1時間の内訳が分からない書き込みは、こちらに入れると見積もりが小さく出すぎません。

空欄のときは円を出しません。見積もり当日のレートを入れてください。

サブスクのプラン(Pro / Max / Team)は月額・席単位の料金で、Claude Code の利用は料金に含まれます。この計算機はサブスクの料金や利用枠を計算しません。サブスクで使う場合、ここでの金額は「誰がどれくらい使うか」を比べる物差しとして使ってください。

計算に使っている単価(2026-10-14 時点・公式ページで最新を確認)

単位は100万トークンあたりの USD です。公式の料金ページ(Pricing)の「Model pricing」の表から抜き出しました。料金は変わることがあるため、見積もりの前に公式ページで最新の値を確認してください。

Claude Code の月額を見積もる考え方

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)を API で使うと、料金はトークン(AI が文章を数える単位)の量で決まります。入力・出力のほかに、プロンプトキャッシュ(同じ内容を再利用して安く読み込む仕組み)の書き込みと読み込みにも別々の単価があります。この計算機は、次の式で1人1日あたりの金額を出し、稼働日数と人数を掛けています。

API換算(USD) = ( 入力 × 入力単価
               + 5分キャッシュ書き込み × 5分キャッシュ書込単価
               + 1時間キャッシュ書き込み × 1時間キャッシュ書込単価
               + キャッシュ読み込み × キャッシュ読込単価
               + 出力 × 出力単価 ) ÷ 1,000,000

Claude Code は会話の履歴をリクエストのたびに送るため、長いセッションほどキャッシュ読み込みのトークン数が積み上がります。入力例を入れてみると、読み込みのトークン数が入力より桁違いに多いことが分かります。

料金表に人数を掛けただけの数字は、実際の使い方と離れがちです。人によって使う量の差が大きいので、公式の「コスト管理」ページでも、小さな試験グループで基準になる数字をつかんでから広げることが勧められています(Manage costs effectively、執筆時点)。まず数人で2週間ほど使い、1日あたりのトークン数を測ってからこの計算機に入れると、稟議や予算の説明に使える数字になります。

よくある質問

1日あたりのトークン数はどうやって調べますか

API で契約している場合は、Claude Console の使用量ページで確認できます。試験期間などで管理画面がない場合は、Claude Code が PC 内に保存している会話の記録にトークン数が残っているので、それを集計する方法があります。集計スクリプトと手順は下の有料記事で解説しています。

Pro や Max、Team のプランだといくらになりますか

サブスクは月額・席単位の料金で、この計算機の対象外です。プランの利用枠がトークン何件分にあたるかは、執筆時点で公式ページから確認できませんでした。プランの料金は公式の料金ページで確認してください。

為替レートの初期値が空なのはなぜですか

レートは日々変わるため、古い値で円の金額が出ないよう空欄にしています。見積もり当日のレートを入れてください。計算の流れを見るだけなら「例として 150 を入れる」を使えます。

入力した数字はどこかに送られますか

送られません。計算はブラウザの中だけで行います。閲覧数を数えるため、開いたページの URL だけを運営者のサーバに送ります(Cookie や外部の解析サービスは使いません。詳しく)。
