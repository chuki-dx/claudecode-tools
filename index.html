Tools無料ツール

  • Claude Code 権限設定(settings.json)ジェネレーター

    「.env を読ませない」「curl などで外部に送らせない」「git push は確認」といった方針を選ぶと、settings.json の deny / ask / allow のルールを出力します。実機で止まると確認したルールと、個別には確認していないルールを分けて表示します。

  • CLAUDE.md テンプレート生成

    用途・言語・守ってほしいこと・触ってはいけないフォルダを選ぶと、Claude Code が起動時に読む CLAUDE.md のひな形を出力します。最初の3行版にも切り替えられ、200行以内に収まっているかを行数で表示します。

  • Claude Code スキル(SKILL.md)雛形生成

    スキル名・説明・いつ使うか・手順・出力の形を入れると、.claude/skills/<名前>/SKILL.md のひな形を出力します。スキル名の書き方と frontmatter の形を確かめます。議事録の要約などの例つきです。

  • Claude Code つまずき早見表(Windows・情シス向け)

    allow が効かない、deny をすり抜ける、PowerShell の文字化け、CSV の BOM など、実機で起きたつまずきを症状・原因・対処の表にまとめました。キーワードと分類で絞り込めます。

  • Claude Code API 料金 見積もり計算機

    人数・1日あたりのトークン数・稼働日数・モデルから、API の従量課金で使ったときの月額を USD と円で計算します。単価は 2026-10-14 時点で公式ページから確認した値です。

Guides解説

ツールの背景にある仕組みや注意点を、公式ドキュメントと実機の確認結果にもとづいて解説しています。解説記事の一覧

  • CLAUDE.md の書き方:置き場所の違いと短く保つコツ
  • Claude Code のスキル(SKILL.md)入門:業務手順を Claude に覚えさせる

  • Windows で Claude Code を使うときのつまずき10選と対処
  • Claude Code を社内で試す前に確認すること(プラン・PC・ネットワーク・社内ルール)
  • Claude Code に .env を読ませない設定と、その限界(Windows で確認)
  • 総務・経理など非エンジニアに Claude Code を教えるときの進め方
