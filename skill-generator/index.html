スキル(SKILL.md)とは

スキルは、手順と出力の形に名前を付けて呼び出せるようにしたものです。.claude/skills/<スキル名>/SKILL.md に置くと、依頼が description に合えば Claude Code が自分で使い、/スキル名 のように名前でも呼べます。CLAUDE.md が「毎回読ませる前提」なのに対して、スキルは「その作業を頼まれたときに使う手順書」です。

このツールが出力する形

先頭の --- で囲んだ部分(frontmatter)は、name と description の2項目だけにしています。社内標準セットで、Windows 11 と Claude Code 2.1.296 が5本とも読み込み、claude plugin validate .claude/skills も通った形と同じです(2026年10月)。

  • 公式ドキュメントでは、frontmatter の項目はすべて省略可能で、description は書くことが推奨、name を省くとフォルダ名が呼び出し名になるとされています(執筆時点)。
  • description は、一覧に載るときに when_to_use と合わせて 1,536 文字で切られるとされています。大事な使い道を先に書きます。
  • スキル名は、社内標準セットと同じ英小文字・数字・ハイフンに限っています。synced と anthropic-skills は公式ドキュメントで予約されている名前のため使えません。
  • 説明に「: 」のような YAML で意味を持つ書き方が入ると、frontmatter が読めなくなることがあります。このツールはその場合だけ説明を " で囲みます。
  • 確認なしでツールを使わせる allowed-tools は入れていません。公式ドキュメントで、プロジェクトの信頼の確認と関係なく効くとされているためです。

使い方

  1. 上の欄を埋めるか、例を読み込んで書き換え、「SKILL.md を保存」を押します。
  2. 表示された置き場所(例: .claude/skills/minutes-summary/)にフォルダを作り、保存した SKILL.md を置きます。
  3. そのフォルダで claude plugin validate .claude/skills を実行し、「使えるスキルの名前を一覧にして」と頼んで、一覧に出るかを確かめます。
  4. 架空のデータで一度頼み、出力の形どおりになるかを確かめてから配ります。

よくある質問

スキルが一覧に出ません

.claude/skills/<名前>/SKILL.md の位置と、先頭行が --- で始まっているかを確かめ、claude plugin validate .claude/skills を実行してください。ほかのつまずきは つまずき早見表 にまとめています。

スキルが自動で使われません

description の言葉と、頼み方の言葉が合っていないことがあります。「いつ使うか」に、利用者がふだん使う言葉を足してください。/スキル名 で直接呼ぶこともできます。

入力した内容はどこかに送られますか

送られません。このページは HTML と JavaScript だけで動き、生成もブラウザの中で行います。アクセス解析のタグも入れていません。
