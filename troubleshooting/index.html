Claude Code つまずき早見表(Windows・情シス向け)

Claude Code を Windows で使う・社内に配るときに、私の検証や研修の準備で実際に起きたことを、症状から引けるようにまとめました。各行に出典の記事を付けています。

症状で絞り込む

症状原因対処出典

「実機で起きた」は、Windows 11 と Claude Code 2.1.296 で、記事の検証・研修の準備の中で起きたことです(2026年10月)。「公式ドキュメントの記載を確認」は、記事を書くときに公式ドキュメントで確かめた内容で、実機では試していません。

この早見表について

載せているのは、中小DXラボの記事と本で、実際に起きたこと、または公式ドキュメントで確かめて書いたことだけです。ネット上でよく聞く話でも、私が確かめていないものは載せていません。そのため、ここに無い症状も当然あります。

権限設定(settings.json)の deny は「うっかり読む・送る」を防ぐ網で、どんな方法でも止める壁ではありません。CLAUDE.md は Claude が読んで従おうとする説明書きで、強制力はありません。多くのつまずきは、この2つの役割の違いから起きています。

  • 止めたいルールを作る: 権限設定ジェネレーター
  • 毎回読ませる前提を書く: CLAUDE.md テンプレート生成
  • よく頼む作業を手順にする: スキル(SKILL.md)雛形生成

公式ドキュメント(執筆時点)

  • Configure permissions(deny の効く範囲、信頼の確認と allow の関係)
  • How Claude remembers your project(CLAUDE.md の置き場所、200行の目安)
  • Extend Claude with skills(SKILL.md の置き場所と frontmatter)

このページの内容は 2026年10月時点のものです。仕様は変わることがあるため、公式ドキュメントと手元の実機で確認してください。
