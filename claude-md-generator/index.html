CLAUDE.md とは

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)は、会話を始めるたびに前回の中身を覚えていない状態から始まります。毎回同じ説明をしなくて済むように、セッションの最初に読ませる説明書きが CLAUDE.md です。中身はただの Markdown(見出しや箇条書きを書けるテキスト)です。

最初は「立場・道具・優先順位」の3行で十分です。同じ説明を2回したら1行足す、を続けて育てます。公式ドキュメントでは、1ファイル200行以下が目安とされています(執筆時点)。長くなるほど読み込みの負担が増え、守られにくくなるためです。このツールは出力の行数を数え、200行を超える組み合わせは出力しません。

どこに置くか

置き場所によって効く範囲が変わります。公式ドキュメント(執筆時点: 2026年10月)で確認した置き場所です。

置き場所効く範囲書く内容
組織用(Windows: C:\Program Files\ClaudeCode\CLAUDE.md)その PC で使う全員組織全体に配りたいルール。管理者が置く
自分用・全プロジェクト共通(~/.claude/CLAUDE.md)自分が使うすべてのプロジェクト自分の好み、どのプロジェクトでも共通のルール
プロジェクト用(作業フォルダ直下の CLAUDE.md または .claude/CLAUDE.md)そのフォルダで作業する全員チームで共有する前提・手順。このツールの出力はここに置く想定です
自分用・このプロジェクトだけ(作業フォルダ直下の CLAUDE.local.md)自分だけ共有しない個人的なメモ。.gitignore に入れておく

自分用の ~/.claude/CLAUDE.md は、どのフォルダで起動しても一緒に読み込まれます。他の人に配る CLAUDE.md を自分の PC で試すと、自分用の指示の影響も受けるので注意してください(つまずき早見表 に実例があります)。

禁止したいことは settings.json に書く

CLAUDE.md は強制力のある設定ではなく、Claude が読んで従おうとする説明書きです。「.env を読まない」と書いても、止める仕組みにはなりません。確実に止めたい操作は、権限設定ジェネレーター で settings.json の deny ルールにします。CLAUDE.md には「なぜそうするのか」という前提を残し、止める役割は権限設定に任せる、という分担です。

なお、私の検証では、CLAUDE.md に「読まない」と書いてあると Claude は読み取りを試みませんでした。deny が効くかをテストするときは、CLAUDE.md を一時的に別名にしてから試します。

よくある質問

3行版とひな形のどちらから始めればよいですか

自分1人で使い始めるなら3行版で十分です。部署のフォルダに配るなら、フォルダの使い方と守ることが入ったひな形が向いています。

すでにフォルダにファイルがある場合はどうしますか

Claude Code の中で /init と入力すると、フォルダの中身を見て最初の CLAUDE.md を作ってくれます。すでに CLAUDE.md がある場合は、上書きせずに改善案を出してくれます。このツールの出力と見比べて、自分しか知らない前提を書き足す使い方もできます。

入力した内容はどこかに送られますか

送られません。このページは HTML と JavaScript だけで動き、生成もブラウザの中で行います。閲覧数を数えるため、開いたページの URL だけを運営者のサーバに送ります(Cookie や外部の解析サービスは使いません。詳しく)。
