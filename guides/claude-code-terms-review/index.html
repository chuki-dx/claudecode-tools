Claude Code の利用規約を社内審査で確認する手順:適用される規約・PDF・施行日・データの扱い

公開: 2026年11月26日 ・ 中小DXラボ ・ 内容は執筆時点(2026年11月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • 適用される規約は利用形態で決まります。公式ドキュメントによると、Team・Enterprise・Claude API は Commercial Terms of Service、Free・Pro・Max・Ultra は Consumer Terms of Service が対象です。
  • 原文は Anthropic の Legal Center にあり、PDF、Effective(施行日)、版の履歴の確認先が揃っています。審査では日付と版を記録しておくと追跡できます。
  • データの学習、出力の権利、DPA の記載を確認し、条文の解釈や自社への適用の可否は法務や公式窓口で判断してください。

まず、どの規約が適用されるかを判定する

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)の規約は、使い方で分かれます。公式ドキュメントによると、利用は次の規約の対象です。

  • Commercial Terms of Service:Team、Enterprise、Claude API の利用者向け
  • Consumer Terms of Service:Free、Pro、Max、Ultra の利用者向け

Claude API を直接使う場合も、Amazon Bedrock や Google Cloud の Agent Platform 経由で使う場合も、既存の商用契約が Claude Code の利用に適用されます。Anthropic と別途合意している場合は除きます。

審査では、まず社内の利用形態(Team・Enterprise、API、クラウド経由、個人プラン)を決め、この区分に当てはめます。

出典: Legal and compliance

規約の原文・PDF・施行日はどこにあるか

Anthropic の規約のページ(Legal Center)によると、規約とポリシーが一覧になり、各文書に「View more」と「PDF」のリンクがあります。日付は次のとおりです。

  • Consumer Terms of Service(個人向け):Oct 8, 2025
  • Commercial Terms of Service(法人向け):Jun 17, 2025
  • Data Processing Addendum(法人向け):Feb 24, 2025
  • Usage Policy(全ユーザー):Nov 12, 2026
  • Service Specific Terms(法人向け):Aug 31, 2026
  • Privacy Policy(個人向け):Sep 10, 2026
  • Supported Regions Policy(全ユーザー):Nov 12, 2026

一覧の説明では、Consumer Terms は Free、Pro、Max での Claude Code 利用を含むとされています。Claude Code の公式ドキュメントは Ultra も挙げているため、Ultra を使う場合は公式ドキュメントで確認してください。

Amazon Bedrock、Google Cloud の Vertex、Microsoft Foundry 経由では、マーケットプレイス事業者に支払い、その事業者の規約も適用されると書かれています。日付は執筆時点(2026年11月)の一覧のものです。審査の時点で原文を再確認してください。

出典: Legal Center

Commercial Terms のページで見る点

Commercial Terms of Service のページには、Download PDF、Effective: Jun 17, 2025、Audience: Business、Version history が表示されます。

契約の相手と成立

本文では、顧客が EEA、スイス、英国に居住する場合の Anthropic は Anthropic Ireland, Limited、それ以外は Anthropic, PBC とされています。組織を代表して契約するには法的権限が必要で、消費者向けではないとも書かれています。Effective Date は、顧客が最初に電子的に同意した日と最初にサービスへアクセスした日の早いほうです。

出力の権利と DPA

適用法で認められる範囲で、顧客は入力(Inputs)の権利を保持し、出力(Outputs)を所有するとされています。出力に関する権利の譲渡は、顧客が規約を守っていることが条件です。また、Anthropic は Customer Content でモデルを学習させてはならないと書かれています。データは DPA(個人データの処理に関する付属契約)に従って処理され、DPA は規約に参照により組み込まれています。

条文の解釈や、自社への適用の可否は、法務や公式窓口で確認してください。

出典: Commercial Terms of Service

データの学習はプランで異なる

公式ドキュメントでは、Free、Pro、Max、Ultra は、データをモデル改善に使うかを利用者が選べ、設定が有効なときは Claude Code の利用も学習に使われると書かれています。

Team、Enterprise、API、サードパーティのプラットフォーム、Claude Gov では、商用規約の下で Claude Code に送ったコードやプロンプトで生成モデルを学習しません。ただし、顧客が自らデータ提供を選んだ場合(例:Developer Partner Program)は除きます。このプログラムは組織の管理者が明示的に参加でき、Anthropic の第一者 API のみが対象で、Amazon Bedrock と Google Cloud の Agent Platform は対象外です。保存期間は別記事で扱っています。

出典: Data usage

自社の製品・サービスに組み込む場合の条件

公式ドキュメントによると、別途合意がない限り、Claude Code を自社の製品やサービス(ホスト型サンドボックスなど)に事前インストールまたは実行するには、Commercial Terms of Service への同意と次の条件の遵守が必要です。

  • Claude Code のバイナリを改変しない。Anthropic の公開どおりにインストール・実行し、組み込まれた認証方法を削除・無効化・制限しない
  • エンドユーザーに代わって Claude の利用料を支払ったり、再販・仲介したりしない。各エンドユーザーが自分の API キー、Claude のサブスクリプションの認証情報、またはサードパーティ推論プロバイダーの認証情報で認証する

Claude Code や Anthropic の名称・ロゴは、自社の製品名、機能名、会社名、ロゴの一部には使えず、Anthropic が開発・推奨・提携していると示す使い方もできません。事前インストールや Claude Code の実行を、平文で正確に書くことは認められています。

出典: Legal and compliance

更新の通知と、審査で併せて見る資料

Legal Center のページ下部のフォームに登録すると、Commercial Terms of Service、Data Processing Addendum、Usage Policy、Supported Regions Policy、Service Specific Terms の更新時にメールが届きます。Consumer Terms of Service と Privacy Policy は、この一覧に書かれていません。

セキュリティ認証や監査レポートは Trust & Compliance Center にまとめられ、SOC 2 Type II などが挙げられています。また、公表された Commercial Terms はすべての法人顧客に一律に適用され、交渉の対象ではないと書かれています。

出典: Legal Center

よくある質問

Team プランで Claude Code を使う場合、どの規約が適用されますか?

Legal Center によると、API と Team・Enterprise プランには Commercial Terms of Service が適用され、Team や Enterprise 経由の Claude Code の利用にも同じ規約が適用されます。DPA は Commercial Terms に参照により組み込まれ、法人顧客に自動的に適用されると書かれています。

出典: Legal Center

規約の PDF と版の履歴はどこで確認できますか?

Commercial Terms of Service のページに、Download PDF、Effective、Version history が表示されます。

出典: Commercial Terms of Service

契約社員や委託先にも使わせてよいですか?

Legal Center の FAQ は、Commercial Terms について、従業員、関連会社の従業員、契約者(contractors)、自社を代理して行動するその他の権限を持つ利用者にアクセスを付与でき、利用者の規約遵守とアカウント上のすべての活動には顧客が責任を負うと回答しています。個別の判断は法務や公式窓口で確認してください。
