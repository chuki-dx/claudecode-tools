Claude Code を API で使うときの料金の見積もり方(トークンの数え方と単価)

公開: 2026年10月14日 ・ 中小DXラボ ・ 単価は 2026-10-14 時点で公式の料金ページから確認した値です

結論

  • API の料金は「トークン数 × 100万トークンあたりの単価」を、入力・キャッシュ書き込み・キャッシュ読み込み・出力の種類ごとに足して出します。
  • Claude Code は会話の履歴を毎回送るため、キャッシュ読み込みのトークン数が大きくなりやすい点が、ふつうのチャットの見積もりと違います。
  • 料金表だけでは部署の月額は決まりません。公式ドキュメントのとおり、少人数で試して実際のトークン数を測ってから見積もります。

トークンとは

トークンは、AI のモデルが文章を処理するときの単位です。API(プログラムから Claude を使う窓口)の料金は、文字数ではなくトークン数で決まります。Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)を API の従量課金で使う場合も同じで、1回の依頼の裏で何度もモデルとやり取りし、そのたびにトークンが数えられます。

見積もりで区別するトークンは、次の4種類(キャッシュ書き込みを5分と1時間に分けると5種類)です。

  • 入力: モデルに送った内容のうち、キャッシュを使わなかった分
  • キャッシュ書き込み: 次のリクエストで再利用するために、送った内容をキャッシュに保存した分。保存期間は5分と1時間の2種類で単価が違います
  • キャッシュ読み込み: 保存済みの内容を再利用した分。入力より大幅に安い単価です
  • 出力: モデルが返した内容。公式ドキュメントでは、思考(thinking)のトークンも出力として課金されるとされています

単価(2026-10-14 時点)

公式の料金ページの「Model pricing」の表から、Claude Code でよく使う3モデルを抜き出しました。単位は100万トークンあたりの USD です。料金は変わることがあるため、見積もりの前に公式ページで最新の値を確かめてください。

  • 米国内だけで処理する指定(inference_geo を us にする)をすると、すべての単価が1.1倍になります。
  • 高速モード(fast mode)は別の単価です。

計算式

1人1日あたりの金額は、モデルごとに次の式で出します。

1日の金額(USD) = ( 入力 × 入力単価
                 + 5分キャッシュ書込 × その単価
                 + 1時間キャッシュ書込 × その単価
                 + キャッシュ読込 × その単価
                 + 出力 × 出力単価 ) ÷ 1,000,000

月額(USD) = 1日の金額 × 稼働日数 × 人数
月額(円)  = 月額(USD) × 為替レート

架空の数字での計算例

Sonnet 5.5 で、1人1日あたり入力 1,040、1時間キャッシュ書き込み 190,000、キャッシュ読み込み 2,170,000、出力 31,000 トークン使ったとします(架空の数字です)。

稼働日を月20日とすると、1人あたり約25.78 USD/月です。この例では、トークン数はキャッシュ読み込みが飛び抜けて多い一方、金額ではキャッシュ書き込みと出力の割合が大きくなっています。トークン数の多さと金額の大きさが一致しないため、種類ごとに分けて計算することが大切です。

トークン数の調べ方

見積もりの精度は、1日あたりのトークン数をどれだけ実態に近づけられるかで決まります。執筆時点の公式ドキュメントでは、次の手段が案内されています。

  • /usage コマンド: 今のセッションのトークン数を、種類ごとに表示します。表示される金額はトークン数から定価で計算した見積もりで、請求の正式な値は Claude Console の使用量ページで確かめるとされています。
  • Claude Console の使用量ページ: API で契約している場合の、請求のもとになる数字です。

このほか、Claude Code は会話の記録を PC の中(ユーザーフォルダの .claude の下)に保存しており、そこにもトークン数が残っています。ただし記録は既定で30日たつと削除されるため、測るなら期間を決めて早めに集計します。

公式ドキュメントには、企業での利用の平均として、開発者1人あたり稼働日1日で約13 USD、月150〜250 USD、利用者の90%は1日30 USD 未満、という数字も載っています。あわせて、自社の数字は小さな試験グループで基準をつかんでから広げるように、と書かれています。平均値は目安にとどめ、自分たちの使い方で測ることをおすすめします。

サブスクのプランとの違い

Pro・Max・Team などのサブスクで使う場合、Claude Code の利用は月額に含まれます。公式ドキュメントでは、Pro と Max の利用者には /usage のセッションの金額は請求と関係しないと説明されています。この場合、API 換算の金額は「誰がどれくらい使っているか」を比べる物差しとして使い、プランの割り当てを考える材料にします。

金額を抑える考え方

  • モデルを使い分ける: 公式ドキュメントでは、Sonnet はほとんどのコーディング作業をこなせて Opus より安く、Opus は複雑な設計判断などに取っておくよう勧められています。
  • 関係のない作業に移るときは /clear: 履歴が長いほど、毎回送る量が増えます。
  • effort(推論の深さ)を調整する: 公式ドキュメントでは、深い推論が要らない単純な作業は /effort で effort を下げると費用を抑えられるとされています。

よくある質問

/usage に出る金額は、そのまま請求額ですか

公式ドキュメントでは見積もりとされています。API の請求の正式な値は Claude Console の使用量ページで確かめます。サブスクの場合は請求と関係しません。

円での金額はどう出しますか

料金は USD で決まっています。見積もりの日の為替レートを掛けて円にし、資料には使ったレートと日付も書いておきます。

サブスクの利用枠はトークン何件分ですか

執筆時点の公式の料金ページでは、プランの利用枠は「Pro の何倍」という相対的な書き方で、トークン数では示されていません。

月額をブラウザで計算する

Claude Code API 料金 見積もり計算機 に、人数・1日あたりのトークン数・稼働日数・モデルを入れると、この記事の式で月額を USD と円で計算できます。上の計算例の数字も読み込めます。
