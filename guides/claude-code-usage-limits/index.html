Claude Code の使用量上限に達したら?表示・リセット・待つか追加するかの判断

公開: 2026年10月17日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)は、上限に達すると表示されたリセット時刻まで次のリクエストを止めます。まず /usage で状況を確認します。
  • 続ける手段は、待つ、モデルを変える(Opus・Sonnet の上限の場合)、使用量クレジットを有効にする、プランを上げる、などです。使用量クレジットは標準の API 料金で、サブスクリプションとは別に請求されます。
  • Team や Enterprise は個人プランと扱いが異なります。社内で配る前に、自社のプランと使用量クレジットの有効化を確認してください。

Pro・Max の上限は五時間と週次で、Claude と共通

公式ヘルプセンターによると、Pro と Max には五時間のセッション上限と週次の上限があり、Max には Fable 用の週次上限が別にあります。これらは Claude と Claude Code で共通で、両方の利用が同じ上限に数えられます。上限に近づくと警告が出ます。以下は執筆時点(2026年10月)の記載に基づきます。

セッション上限に達したとき応答の途中であれば、進行中のステップを終えるために少しだけ作業が続くことがあり、その間は Usage limit reached · wrapping up と表示されます。この猶予は小さく上限があり、使った分は週次上限に数えられます。すでに進行中の応答だけが対象で、上限到達後に送る新しいメッセージには使えません。Pro では週次の利用期間につき最大1回、Max では週次上限の範囲内で、セッション上限に達するたびに適用されることがあります。段階的に提供中のため、まだ使えないアカウントもあります。

出典: Use Claude Code with your Pro or Max plan

上限に達したときの表示とリセット時刻の見方

公式ドキュメントによると、サブスクリプションの利用枠を使い切ると、次のいずれかのメッセージが表示されます。

You've hit your session limit · resets 3:45pm
You've hit your weekly limit · resets Mon 12:00am
You've hit your Opus limit · resets 3:45pm
You've hit your Sonnet limit · resets 3:45pm

Claude Code は、メッセージに示されたリセット時刻まで追加のリクエストを止めます。セッションと週次の上限は全モデル共通なので、モデルを変えても使えるようにはなりません。Opus と Sonnet の上限はそれぞれのモデルファミリーだけが対象のため、/model でファミリー外のモデルに切り替えれば作業を続けられます。ただしモデルごとにキャッシュが別なので、次のリクエストは会話全体を読み直し、キャッシュは効きません。

大きなワークフローの並列実行のような集中的な作業では、セッション枠のリセット前に週次枠を使い切ることがあります。

確認と待機の操作

  • /usage で、プランの上限とリセット時刻を確認できます。
  • /usage-credits で、Pro・Max は追加利用を購入でき、Team・Enterprise は管理者に依頼できます。
  • 上限の手前では You've used 85% of your session limit · resets 3:45pm のような警告が出ることがあります。
  • claude.ai のサブスクリプションでサインインした対話セッションでは、開いたセッションで待機し、リセット後に中断したタスクを続けることもできます。v2.1.234 より前はこの待機はありませんでした。
  • Desktop アプリの Code タブでは、セッション上限のカードに Auto-continue when limits reset のチェックボックスがあります(週次上限のカードにはありません)。CLI の /config にある Continue automatically at usage limit とは別設定なので、オフにするときはそれぞれ行います。

待つか追加するか:Pro・Max で公式が挙げる選択肢

公式ヘルプセンターが挙げる、上限に達したときの選択肢です。アップグレードは「常に上限に達する」場合の選択肢として書かれており、たまに当たる程度なら待つ選択肢もあります。

Pro プランの場合

  • 常に上限に達し、大きなリポジトリで容量が必要なら Max 5x を検討する
  • 使用量クレジットを有効にし、五時間のセッション上限または週次上限の後も Pro のまま使い続ける
  • Claude Console アカウントに切り替え、集中的なコーディング向けに API 利用クレジットを購入する
  • 上限のリセットまで待つ

Max プランの場合

  • Max 5x で常に上限に達するなら Max 20x を検討する
  • 使用量クレジットを有効にし、セッション上限、通常の週次上限、Fable の別枠の週次上限の後も使い続ける
  • Claude Console での API 利用クレジット購入、またはリセット待ち

注意点として、Max に含まれる月次 API クレジットは、追加利用を含め、Claude Code と Claude アプリでは使えません。

出典: Use Claude Code with your Pro or Max plan

使用量クレジットの仕組み・設定・費用面の注意

公式ヘルプセンターによると、使用量クレジットは Pro・Max 5x・Max 20x の個人契約で、含まれる上限に達した後も、標準の API 料金による従量課金に切り替えて使い続ける仕組みです。有効にしていれば、上限に達しても止まらず、リクエストは使用量クレジットで処理されます。設定は Claude アカウントの Settings > Usage で行います。

  1. Usage credits セクションで「Enable」をクリックし、未設定なら支払い方法を登録する
  2. 「Adjust limit」で月間の上限額を決める(「Set to unlimited」で制限なしも選べます)
  3. 「Add funds」で前払いする。残高が閾値を下回ったら自動購入する auto-reload も設定できます

注意点

  • 使用量クレジットはサブスクリプションとは別に請求され、追加料金として請求書に表示されます。最新の金額は公式の料金ページで確認してください。
  • 使用は、月間の上限額に達するか、auto-reload オフで残高が尽きるまで続きます。
  • 切り替わる瞬間は「上限に近づいている」通知が残ることがあり、次のリクエストが通ると Now using credits に変わります。止まったわけではありません。
  • 上限のリセット時期は変わりません。モバイルアプリ経由で契約した場合、有効化と購入は Web 版だけです。
  • 多くの場合は失効しませんが、日本など一部の地域では、2026年9月10日開始として、購入後六か月で失効します。失効の7日前にメールが届きます。

Team・Enterprise で配る場合の考え方

公式ヘルプセンターによると、使用量ベースの Enterprise プラン(セルフサーブを含む)には席ごとの使用上限がなく、利用量に応じて API 料金で請求されます。

Team プランと席ベースの Enterprise プランでは、使用量クレジットを有効にすると、メンバーは含まれる上限に達した後も Claude、Cowork、Claude Code で作業を続けられます。Team プランに含まれる月次 API クレジットは、Claude Code や Claude アプリでは使えません。どのプランか、使用量クレジットを有効にするかは請求に関わるため、配る前に確認してください。

よくある質問

Claude Code の上限はいつリセットされますか?

上限に達すると、メッセージにリセット時刻が表示されます。たとえば週次上限なら You've hit your weekly limit · resets Mon 12:00am の形式で、その時刻までリクエストは止まります。/usage でもプランの上限とリセット時刻を確認できます。

出典: Error reference

Server is temporarily limiting requests と出たら上限に達したのですか?

いいえ。公式ドキュメントによると、プランの上限とは無関係の、短時間のサーバー側の制限です。v2.1.199 以降は表示の前にバックオフ付きで自動再試行されます。少し待って再試行し、続く場合は公式のステータスページを確認してください。

出典: Error reference

Max に含まれる月次 API クレジットは、上限を超えた分に使えますか?

使えません。公式ヘルプセンターによると、Max に含まれる月次 API クレジットは、追加利用を含め、Claude Code と Claude アプリでは使えません。上限後に続けるには、使用量クレジットなど別の手段を検討します。
