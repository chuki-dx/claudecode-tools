Claude Code 解説記事

中小企業で Claude Code を試す・配る・予算を説明するときに知っておきたいことを、執筆時点(2026年10月)の公式ドキュメントと、Windows 11・Claude Code 2.1.296 での確認結果にもとづいて解説します。各記事から、内容に対応する無料ツールを使えます。

  • Claude Code の権限設定(deny/ask/allow)の基本と、効く範囲・効かない範囲

    ルールの評価の順番、設定ファイルの置き場所と優先順位、書き方を解説します。deny で止まる操作と、スクリプト経由の読み取りのように止まらない操作を整理しました。

    対応するツール: 権限設定(settings.json)ジェネレーター

  • CLAUDE.md の書き方:置き場所の違いと短く保つコツ

    組織用・自分用・プロジェクト用・ローカル用の違いと読み込まれ方、最初の3行の例、200行以内に保つ書き方、書いてはいけないものをまとめました。

    対応するツール: CLAUDE.md テンプレート生成

  • Claude Code のスキル(SKILL.md)入門:業務手順を Claude に覚えさせる

    スキルの置き場所、name と description の書き方、自動で使われる条件、本文に書く手順と出力の形、配る前の確かめ方を解説します。

    対応するツール: スキル(SKILL.md)雛形生成

  • Claude Code を API で使うときの料金の見積もり方(トークンの数え方と単価)

    入力・キャッシュ書き込み・キャッシュ読み込み・出力のトークンと単価(2026-10-14 時点)、計算式と計算例、トークン数の調べ方、サブスクとの違いを整理しました。

    対応するツール: API 料金 見積もり計算機

  • Windows で Claude Code を使うときのつまずき10選と対処

    PowerShell の文字化けと実行ポリシー、CSV の BOM、allow が効かない、deny をすり抜ける読み取りなど、Windows で起きやすい10個を症状・原因・対処で解説します。

    対応するツール: つまずき早見表

  • Claude Code を社内で試す前に確認すること(プラン・PC・ネットワーク・社内ルール)

    必要なプラン、Windows の要件、プロキシで許可する通信先、会話データの扱い、インストール後の確認を、試す前のチェックリストにまとめました。

    対応するツール: CLAUDE.md テンプレート生成 ・ 権限設定(settings.json)ジェネレーター

  • Claude Code に .env を読ませない設定と、その限界(Windows で確認)

    deny ルールで .env の読み取りと cat は止まり、Python スクリプト経由の読み取りは止まりませんでした。Windows 11 での確認結果と、公式ドキュメントにある限界を整理しました。

    対応するツール: 権限設定(settings.json)ジェネレーター

  • 総務・経理など非エンジニアに Claude Code を教えるときの進め方

    研修なしで渡すと起きやすいこと、90分×3回の組み立て方、架空データと「条件」での判定、広げる順番と効果の記録の仕方を解説します。

    対応するツール: つまずき早見表
