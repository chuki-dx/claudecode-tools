Claude Code の CLI コマンド一覧:claude・claude -p・claude update の使い分け

公開: 2026年10月24日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • 日常の入口は、対話を始める claude、1回問い合わせて終了する claude -p "query"、直近の会話を続ける claude -c の3つです。
  • 更新は claude update、バージョンを指定した導入や再導入は claude install [version]、状態の確認は読み取り専用の claude doctor です。
  • claude mcp やバックグラウンドセッション系、claude purge などは、バージョンや環境の条件、削除を伴う点があるため、社内に配る前に公式ドキュメントで確認してください。

起動・問い合わせ・再開の基本コマンド

この記事は、公式ドキュメントの CLI reference にあるコマンド表をもとに整理したものです。Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)では、セッションの開始、内容のパイプ渡し、会話の再開、更新の管理を claude から始まるコマンドで行う、と公式ドキュメントでは説明されています。執筆時点(2026年10月)の表に基づくため、最新の内容は公式ドキュメントで確認してください。

対話で始める

  • claude:対話セッションを開始します。
  • claude "query":最初のプロンプトを付けて対話セッションを開始します。例は claude "explain this project" です。

1回で終える

claude -p "query" は SDK 経由で問い合わせたあと終了します。例は claude -p "explain this function" です。ファイルの内容をパイプで渡して処理させる使い方も表に載っており、例ではログファイルを渡して explain させています。

続きから再開する

  • claude -c:現在のディレクトリで直近の会話を続けます。
  • claude -c -p "query":SDK 経由で続けます。例は claude -c -p "Check for type errors" です。
  • claude -r "<session>" "query":ID または名前を指定してセッションを再開します。例は claude -r "auth-refactor" "Finish this PR" です。

出典: CLI reference

更新・インストール・診断のコマンド

claude update は最新バージョンへ更新するコマンドです。claude install [version] はネイティブバイナリのインストールまたは再インストールで、2.1.118 のようなバージョンのほか、stable や latest を指定できます。例は claude install stable です。手順の詳細は、公式ドキュメントの Install a specific version の項目を確認してください。

claude doctor は、セッションを始めずに、インストールの状態、設定ファイルの検証エラー、Remote Control の利用資格などを読み取り専用で表示します。修正まで行えるセッション内のチェックは /doctor です。

サブコマンドを打ち間違えると、Claude Code は最も近い候補を示して終了し、セッションは始まりません。例として claude udpate では Did you mean claude update? と表示されます。

認証まわりのコマンド

  • claude auth login:Anthropic アカウントにサインインします。--email でメールアドレスを事前入力、--sso で SSO 認証を強制できます。--console を使うと、Claude サブスクリプションではなく Anthropic Console で API 利用量に応じた課金でサインインします。
  • claude auth logout:Anthropic アカウントからログアウトします。
  • claude auth status:認証状態を JSON で表示します。--text で人が読みやすい形式になります。ログイン中は終了コード 0、未ログインは 1 で終了します。

claude auth status の JSON にある authMethod は、none、claude.ai、oauth_token、api_key、api_key_helper、third_party のいずれかです。設定ディレクトリを示す configDirectory フィールドには Claude Code v2.1.268 以降が必要です。

claude setup-token は、CI やスクリプト向けの長期 OAuth トークンを生成します。トークンは端末に表示されるだけで保存されず、Claude サブスクリプションが必要です。表示された値の控えの管理には注意が必要です。

出典: CLI reference

MCP とプラグインのコマンド

claude mcp は Model Context Protocol(MCP)サーバーを設定するコマンドです。使い方の詳細は、公式ドキュメントの MCP のページを参照する形になっています。

  • claude mcp login <name>:設定済み MCP サーバーの OAuth フロー(認証の手順)を、対話の /mcp パネルを開かずに実行します。HTTP、SSE、claude.ai コネクタのサーバーで使えます。SSH 越しでは --no-browser を付けると、ブラウザを開かず認可 URL が表示されます。例は claude mcp login sentry です。
  • claude mcp logout <name>:MCP サーバーに保存された OAuth 資格情報を消去します。例は claude mcp logout sentry です。

claude plugin はプラグインを管理するコマンドで、別名は claude plugins です。例は claude plugin install code-review@claude-plugins-official で、サブコマンドは公式ドキュメントの plugin reference にまとまっています。

出典: CLI reference

バックグラウンドセッションと、注意が要るコマンド

claude agents は agent view を開き、並列のバックグラウンドセッションを監視・割り当てします。開くには対話的なターミナルが必要です。個別の操作には claude attach 7c5dcf5d、claude logs 7c5dcf5d、claude stop 7c5dcf5d、claude respawn 7c5dcf5d、claude rm 7c5dcf5d があり、それぞれアタッチ、直近出力の表示、停止、会話を保った再起動、一覧からの削除です。attach と logs で名前の一部を ID の代わりに渡すには、Claude Code v2.1.290 以降が必要です。

削除を伴うコマンド

claude purge [path] は、プロジェクトのローカル状態(トランスクリプト、タスクリスト、デバッグログ、ファイル編集履歴、プロンプト履歴の行、~/.claude.json 内のそのプロジェクトの項目)をすべて削除します。--dry-run で事前に確認でき、-y/--yes で確認を省略、--all で全プロジェクトが対象です。例は claude purge ~/work/repo --dry-run で、最初は --dry-run から試すのが安全です。

環境の条件があるコマンド

claude import [source] は他のコーディングエージェントの設定を取り込みますが、Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude Platform on AWS では使えず、v2.1.213 以降が必要です。claude gateway は管理者向けで、--config の指定が必須です。claude ultrareview [target] の --post は github.com のプルリクエストが対象で、v2.1.227 以降が必要です。

よくある質問

claude と claude -p はどう使い分けますか?

claude は対話セッションを開始し、claude -p "query" は SDK 経由で問い合わせて終了します。対話を続けたい場合は前者、1回の問い合わせで終えたい場合は後者と整理できます。続きは claude -c や claude -c -p "query" で再開できます。

出典: CLI reference

claude update と claude install の違いは何ですか?

公式ドキュメントでは、claude update は最新バージョンへの更新、claude install [version] はネイティブバイナリのインストールまたは再インストールで、2.1.118 のようなバージョン、stable、latest を指定できると説明されています。特定バージョンの手順は公式ドキュメントで確認してください。

出典: CLI reference

ログイン状態はコマンドで確認できますか?

claude auth status で認証状態を JSON で確認できます。--text を付けると人が読みやすい形式になり、ログイン中は終了コード 0、未ログインは 1 で終了します。
