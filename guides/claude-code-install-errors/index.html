Claude Code のインストール・ログインのエラーの調べ方

公開: 2026年10月17日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • 公式ドキュメントには、画面に出たエラー文言から対処を探せる一覧があります。まず表示された文言を一覧と照らすのが近道です。
  • ログインの原因が分からないときは、/logout でサインアウトし、Claude Code を閉じて claude から認証をやり直すと、多くの場合は解決するとされています。
  • ログイン後の 403 や「アクセス権が付与されていない」エラーは、契約・ロール・プロキシなど、Claude Code の外側に原因があることがあります。

まず、エラー文言から対処を探す

執筆時点(2026年10月)の公式ドキュメント(インストールとログインのトラブルシューティング)では、エラーを、画面に出た文言や症状から対処を探す一覧にまとめています。Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)を社内で配るときは、この一覧が問い合わせ対応の起点になります。一覧の例は次のとおりです。

  • command not found: claude:PATH(コマンドを探すフォルダの指定)を直す案内です。
  • EACCES: permission denied:インストール先ディレクトリの権限を直す案内です。
  • unable to get local issuer certificate:社内の CA 証明書を設定する案内です。
  • Failed to fetch version:ネットワークとプロキシの設定を確認する案内です。
  • OAuth error や 403 Forbidden:ログインと認証の節への案内です。

一覧に無い場合は、公式ドキュメントの診断チェックで原因を絞る流れです。なお App unavailable in region は、Claude Code が利用者の国では提供されていないという表示で、設定では対処できません。

出典: Troubleshoot installation and login

インストール時の代表的な症状

具体的な手順は症状ごとに異なるため、公式ドキュメントの該当節で確認してください。

  • Windows で irm is not recognized や 'bash' is not recognized as the name of a cmdlet が出る場合:使っているシェルに合ったインストールコマンドを使う案内です。
  • syntax error near unexpected token '<':インストールスクリプトがシェルスクリプトではなく HTML を返している場合の案内です。
  • PowerShell のインストーラーが完了しても claude が見つからない、または古いバージョンが表示される場合:インストール先を PATH に追加し、新しいターミナルを開く案内です。

出典: Troubleshoot installation and login

ログインできないときは、まず再認証

公式ドキュメントによると、ログインが失敗して原因が分からないときは、再認証で多くの場合は解決します。手順は次のとおりです。

  1. /logout を実行してサインアウトする
  2. Claude Code を閉じる
  3. claude で再起動し、認証をやり直す

ブラウザが自動で開かないときは c を押すと、OAuth URL(ログイン用の URL)をクリップボードにコピーできます。それをブラウザに貼り付けます。狭い端末や SSH で URL が折り返され、クリックできない場合にも使えます。

OAuth error: Invalid code

OAuth error: Invalid code. Please make sure the full code was copied は、ログインコードの期限切れか、コピー時の欠落が原因です。Enter で再試行し、ブラウザが開いたらすぐ完了させます。リモートや SSH では、ブラウザが別のマシンで開くことがあります。その場合は端末に表示された URL を、手元のブラウザで開きます。

再ログインを求められる場合

セッション後に再度ログインを求められるのは、OAuth トークンが期限切れになったためかもしれません。/login で再認証します。頻繁に起きる場合は、システム時計が正確か確認します。トークンの検証が正しいタイムスタンプに依存するためです。

出典: Troubleshoot installation and login

ログイン後の 403 とアクセス権のエラー

ログイン後に API Error: 403 Request not allowed が出る場合、公式ドキュメントは次を確認するよう案内しています。

  • Claude Pro/Max の利用者:サブスクリプションが有効かを、claude.ai の設定画面で確認します。
  • Anthropic Console の利用者:アカウントに「Claude Code」または「Developer」のロールがあるか確認します。管理者が Console の Members ページで割り当てます。
  • プロキシ配下の場合:社内プロキシが API リクエストに干渉することがあります。設定は公式のネットワーク設定のページを参照してください。

アクセスが付与されていないエラー

サインインページに Authorization failed と Claude Code access has not been granted for this account. Contact your administrator. が出る場合は、Claude Enterprise 組織で利用者のロールが Custom になっており、グループに割り当てられたカスタムロールのどれも Claude Code を許可していません。Custom ロールではそれらのカスタムロールからしかアクセスを得られないため、Claude Code 側で何を変えても解決しません。

対処は、組織の Owner に、Claude Code を許可するカスタムロールをグループへ割り当てるか、ロールを Custom から User などの標準ロールへ変更してもらうことです。変更後に claude を実行し、再ログインします。

出典: Troubleshoot installation and login

契約があるのにエラーになる:API キーの上書き

有効なサブスクリプションがあるのに API Error: 400 と This organization has been disabled が出る場合、環境変数 ANTHROPIC_API_KEY がサブスクリプションを上書きしていると公式ドキュメントは説明しています。以前の勤務先やプロジェクトの古い API キーがシェルのプロファイルに残っていると、よく起きます。

ANTHROPIC_API_KEY が存在し、承認済みの場合、Claude Code はサブスクリプションの OAuth 資格情報ではなくそのキーを使います。-p フラグの非対話モードでは、キーがあれば常にそれが使われます。サブスクリプションを使うには、環境変数を解除します。macOS/Linux の場合は次のとおりです。

unset ANTHROPIC_API_KEY
claude

Windows PowerShell の場合は次のとおりです。

Remove-Item Env:ANTHROPIC_API_KEY
claude

恒久的に直すには、~/.zshrc、~/.bashrc、~/.profile にある export ANTHROPIC_API_KEY=... の行を削除します。Windows では PowerShell プロファイル($PROFILE)とユーザー環境変数を確認します。Claude Code 内で /status を実行すると、有効な認証方式を確認できます。

WSL2・SSH・コンテナでのログイン

WSL2、SSH 接続先、コンテナでは、ブラウザが通常は別のホストで開き、リダイレクトが Claude Code のローカルのコールバックサーバーに届きません。サインイン後にブラウザへログインコードが表示されるので、端末の Paste code here if prompted のプロンプトに貼り付けます。WSL2 でブラウザがまったく開かない場合は、BROWSER 環境変数に Windows のブラウザのパスを設定します。

export BROWSER="/mnt/c/Program Files/Google/Chrome/Application/chrome.exe"
claude

コードを貼り付けても反応しない場合は、端末の別の貼り付け操作を試すか、貼り付けたコードを標準入力から読み取る claude auth login を使います。

よくある質問

ログインが何度も失敗する場合、最初に何を試しますか?

公式ドキュメントでは、/logout で完全にサインアウトし、Claude Code を閉じて、claude で再起動して認証をやり直す手順を案内しています。ブラウザが開かないときは c で URL をコピーして手動で開きます。

出典: Troubleshoot installation and login

Claude Code access has not been granted for this account は Claude Code の設定で直せますか?

直せません。Claude Enterprise 組織で利用者のロールが Custom で、割り当て済みのカスタムロールが Claude Code を許可していないことが原因です。組織の Owner にロールの変更を依頼し、その後 claude で再ログインします。

出典: Troubleshoot installation and login

サブスクリプションがあるのに This organization has been disabled と出るのはなぜですか?

公式ドキュメントでは、ANTHROPIC_API_KEY が設定されていて、サブスクリプションの代わりにそのキーが使われていることが原因だと説明しています。環境変数を解除し、シェルのプロファイルからも削除します。

出典: Troubleshoot installation and login
