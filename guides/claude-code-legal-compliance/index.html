Claude Code の利用規約とコンプライアンス:プラン別の規約と確認点

公開: 2026年10月15日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)の規約は、Team・Enterprise・Claude API が商用利用規約、Free・Pro・Max が個人向け規約です。
  • 自社の製品やサービスに組み込む場合は、バイナリの改変禁止や、利用料の肩代わり・再販の禁止などの条件があります。
  • 認証方式や医療系の BAA など判断が難しい点は、公式ドキュメントで確認し、必要なら営業窓口に問い合わせてください。

利用規約はプランごとに分かれる

公式ドキュメントによると、Claude Code の利用は次の規約の対象です。

  • Commercial Terms of Service:Team、Enterprise、Claude API の利用者が対象
  • Consumer Terms of Service:Free、Pro、Max の利用者が対象

Claude API を直接使う場合も、Amazon Bedrock や Google Cloud の Agent Platform 経由の場合も、別途合意がある場合を除き、既存の商用契約が Claude Code にも適用されます。

執筆時点(2026年10月)の公式ドキュメントに基づく内容です。規約本文は導入前に最新版をご確認ください。

自社の製品やサービスに組み込む場合の条件

公式ドキュメントでは、Claude Code を自社の製品やサービスにプリインストールしたり、ホスト型サンドボックスなどのエージェント基盤で動かしたりする場合、別途合意がある場合を除き、商用利用規約への同意と次の条件の順守が必要とされています。

  • Claude Code のバイナリを改変しない。 Anthropic 社の公開どおりにインストールして動かし、Claude アカウントや利用者自身の API キーでのサインインを含む認証方式を、取り除く・無効にする・制限することもできません。
  • 利用者に代わって Claude の利用料を支払う、再販する、仲介することはできません。 各利用者が自分の API キー、Claude のサブスクリプションの資格情報、または第三者推論プロバイダー(Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry)の資格情報で認証し、利用料はその利用者の契約に基づいて直接請求されます。

名称とロゴの扱い

自社製品に Claude Code がプリインストールされている、または Claude Code が動くと、平文で正確に述べることはできます。一方、Claude Code や Anthropic の名称・ロゴを自社の製品名・機能名・会社名やロゴに使うことや、Anthropic が開発・承認・提携していると受け取られる使い方はできません。その他の使用は商標ガイドラインの対象で、書面での許可が必要です。

認証と資格情報:OAuth と API キーの使い分け

Claude Code は OAuth トークンまたは API キーで認証します。公式ドキュメントでは、二つの用途が分けられています。

  • OAuth 認証は、Claude の Free、Pro、Max、Team、Enterprise の購入者向けで、Claude Code などの Anthropic のネイティブアプリの通常の利用を想定しています。
  • 開発者が Claude の機能を使う製品やサービス(Agent SDK の利用を含む)を作る場合は、Claude Console または対応するクラウドプロバイダー経由の API キー認証を使います。

第三者の開発者が自社アプリに Claude.ai のログインを提供することや、Free・Pro・Max の資格情報で利用者のリクエストを中継することは認められていません。Claude.ai の資格情報やセッショントークンの収集・保管・仲介もできません。

制限されないこと

次の2点は制限しないと明記されています。

  • 開発環境、シークレット管理ツール、マシンイメージなどに API キーを設定し、自社の許可した利用者に使わせること。ただし、利用料がキーの所有者に請求され、再販や仲介にならないことが条件です。
  • 利用者が、改変されていない Claude Code に自分の Claude サブスクリプションでサインインすること。

Anthropic 社は、これらの制限を執行する措置を事前の通知なしにとる場合があります。用途で迷うときは営業窓口への問い合わせが案内されています。

医療系のコンプライアンス(BAA)

公式ドキュメントによると、顧客が Anthropic 社と Business Associate Agreement(BAA)を締結している場合、BAA は Claude Code に次の二つの構成で及びます。組織で利用できるものによって異なります。

  • HIPAA 構成:Claude Code の CLI または Claude Desktop の Code タブを、Claude for Enterprise アカウントで使う構成です。組織で HIPAA を有効にし、Claude Code(ローカルモード)と Cowork(ローカルモード)に HIPAA 構成を適用する必要があります。
  • Zero Data Retention(ZDR):該当組織で ZDR を有効にした Claude Code です。ZDR はすべての組織で使えるわけではありません。

HIPAA 構成では、クラウドセッション、Remote Control、Claude モバイルアプリ内の Claude Code、サードパーティのクラウドプロバイダーやゲートウェイ経由の Claude Code は対象外です。対象サービスの全一覧は、案内されている Implementation Guide で確認します。HIPAA や BAA の内容自体はこのページでは説明されていないため、該当しそうな場合は公式ドキュメントと契約窓口でご確認ください。

利用ポリシー・窓口と、社内で試す前の確認

Claude Code の利用は Anthropic Usage Policy の対象です。Pro と Max プランで案内されている利用上限は、Claude Code と Agent SDK の通常の個人利用を前提にしています。

Anthropic Trust Center と Transparency Hub が案内されており、脆弱性の報告は HackerOne の報告フォームから行います。

社内で試す前の確認

  1. 契約中のプランと、適用される規約を確認する
  2. 自社の製品やサービスへ組み込む予定があれば、改変禁止と課金の条件に照らす
  3. 使わせる認証方式(OAuth か API キー)が用途に合うか確認する
  4. 医療情報を扱う可能性があれば、BAA の対象構成か確認する

よくある質問

Team プランで使う場合、どの規約が適用されますか?

公式ドキュメントでは、Team、Enterprise、Claude API の利用者には商用利用規約が適用されるとされています。Free、Pro、Max の利用者は Consumer Terms of Service が対象です。

出典: Legal and compliance

自社サービスに Claude Code を入れて、利用料を会社がまとめて負担できますか?

別途合意がある場合を除き、できません。公式ドキュメントでは、エンドユーザーに代わって利用料を支払う、再販する、仲介することは認められていません。各利用者が自分の資格情報で認証し、利用料はその利用者に直接請求されます。個別の事情は営業窓口にご確認ください。

出典: Legal and compliance

API キーを社内の共通環境に設定して使わせるのは問題ありますか?

公式ドキュメントでは、開発環境、シークレット管理ツール、マシンイメージに API キーを設定し、自社の許可した利用者に使わせることは制限しないとされています。ただし、利用料がキーの所有者に請求され、再販や仲介にならないことが条件です。
