Claude Code の料金・プラン比較:Pro・Max・Team・Enterprise・Console の違いと選び方

公開: 2026年10月17日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • Pro と Max は、Claude(Web・デスクトップ・モバイル)と Claude Code を1つのサブスクリプションで使えます。個人や少人数で試す入口です。
  • SSO やサーバー管理設定、Code Review などは、公式ドキュメントの機能一覧で Team 以上が対象です。金額は公式の料金ページで確認してください。
  • プランの利用枠と Console の API クレジットは別の請求です。ANTHROPIC_API_KEY が設定されていると API 課金になるため、先に確認してください。

Claude Code で何ができるか(Pro・Max)

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)について、公式ヘルプセンターによると、Claude のモデルをターミナルや対応する IDE から直接使えるツールで、複雑なコーディング作業を任せつつ、透明性と制御を保てるとされています。Pro と Max では、Claude(Web・デスクトップ・モバイル)とターミナルの Claude Code を1つのサブスクリプションで使えます。

対応する IDE は、VS Code、Cursor などの VS Code 派生、IntelliJ や PyCharm などの JetBrains 系です。ターミナルと同じ認証情報でログインし、IDE での利用も Claude と Claude Code で共有する同じ利用上限に数えられます。

本記事は執筆時点(2026年10月)の出典に基づきます。金額や利用上限の数値は出典に無いため、最新の内容は公式の料金ページで確認してください。

Pro・Max で使い始める設定と注意点

  1. Pro または Max のサブスクリプションが有効であることを確認する
  2. 公式ドキュメントの Claude Code のページに従い、OS に合わせてインストールする
  3. セットアップ時または初回利用時に、Claude と同じ認証情報でログインする

すでに Claude Console の従量課金(PAYG)でログインしている場合は、Claude Code 内で /login を実行するとサブスクリプションに切り替えられます。

認証の選択肢が出ないとき

  1. /logout で完全にログアウトする
  2. claude update を実行する
  3. ターミナルを完全に再起動する
  4. claude を実行し、正しいアカウントを選ぶ

注意:システムに ANTHROPIC_API_KEY 環境変数があると、Claude Code はサブスクリプション(Pro、Max、Team、Enterprise)ではなくこの API キーで認証します。その結果、プランに含まれる利用枠ではなく API の利用料金が発生します。社内の端末で試す前に、この変数の有無を確認しておくと安心です。

出典: Use Claude Code with your Pro or Max plan

請求の仕組み:プランの枠と API クレジットは別

公式ヘルプセンターでは、Claude Code と Claude Console / Claude API は別の仕組みと説明されています。Claude Code は API クレジットで使い続ける選択肢を示し、自動チャージ(auto-reload)の設定は Console 側にあります。

  • API クレジットを選ぶと、標準の API 料金(Pro/Max のプラン料金とは別)で請求されます
  • Console で auto-reload が有効なら、残高が減ったときにクレジットが自動で追加されます
  • auto-reload が働くのは、API クレジットを使うと選んだ場合だけです

プランの範囲内に収めるには

  • API クレジットの選択肢が出たら断る
  • 利用期間がリセットされるのを待つ
  • /status コマンドで残りの枠を確認する

選択肢を出さないようにするには

  1. ターミナルで claude logout を実行する
  2. claude login を実行し、Pro または Max の認証情報だけで認証する
  3. ログイン中に Claude Console の認証情報を追加しない

こうすると、上限に達しても API クレジットの利用を促されず、プランの枠だけを使うとされています。auto-reload の状態は、Console の Billing 設定で確認・調整します。

Team・Enterprise で使う場合

公式ヘルプセンターによると、新しい Enterprise プランまたはセルフサーブの Enterprise プランでは、Claude Code はすべての Enterprise シートに含まれ、追加購入は不要です。古い Enterprise プラン(Chat と Chat + Claude Code のシート、または Standard と Premium のシート)では、Claude Code を含むシート種別が必要です。オーナーは Organization settings > Organization で Chat + Claude Code / Premium シートを購入・再割り当てできます。

HIPAA 対応の Enterprise プランでは注意が必要です。プライマリオーナーによる HIPAA 構成の適用も、Claude Code のゼロデータ保持(ZDR)も無い場合、Claude Code はシートに含まれて使えますが、BAA の対象外です。保護対象医療情報(PHI)には使わないよう案内されています。

ログインの流れ

  1. ターミナルで claude を入力し、セッションを開始する
  2. ログイン方法を選ぶ(別アカウントでログイン済みなら /login)
  3. 「Claude account with subscription」を選び、OAuth の画面に進む
  4. Team または Enterprise のプランを選び、「Authorize」をクリックする

ログイン後は、組織が提供するものを含め、Claude アカウントのスキルとプラグインが Claude Code に自動で読み込まれます。これには Claude Code v2.1.273 以降が必要です。認証の選択肢が出ないときの手順は、Pro・Max と同じ内容が案内されています。

プラン別の機能差と選び方の目安

公式ドキュメントによると、claude.ai アカウントでログインした場合は、プランによって使える機能が変わります。Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Anthropic Console の API キーで認証する場合、この区分は当てはまりません。Enterprise で HIPAA 構成を適用すると、一部の機能は無効になります。

  • Pro・Max のみ:Computer use、Dispatch(Desktop)
  • Team・Enterprise のみ:Code Review、分析ダッシュボードと貢献メトリクス、Server-managed settings、SSO
  • Enterprise のみ:Enterprise Analytics API、SCIM、Compliance API、Zero Data Retention
  • Remote Control と Channels:Pro・Max は利用可、Team・Enterprise は管理者が有効にした場合
  • Cloud sessions:全プランで利用可。ただし Enterprise はプレミアムシートか Chat + Claude Code シートが必要

Zero Data Retention は標準の Enterprise プランに含まれず、条件を満たすアカウントに Anthropic が別途有効化する必要があります。金額を含む詳しい比較は、公式の Team プランと Enterprise プランのページを参照してください。

選び方の目安

  • 個人や少人数で試す:Pro・Max(Computer use などが使えます)
  • SSO やサーバー管理設定、利用状況の分析が要る:Team 以上
  • SCIM、Compliance API、ゼロデータ保持が要る:Enterprise(ゼロデータ保持は別途の有効化が必要)

よくある質問

ANTHROPIC_API_KEY を設定していると、Pro や Max の枠は使われませんか?

公式ヘルプセンターによると、この環境変数があると Claude Code はサブスクリプションではなく API キーで認証します。そのため、プランに含まれる利用枠ではなく API の利用料金が発生します。

出典: Use Claude Code with your Pro or Max plan

Enterprise プランでは Claude Code を別に購入する必要がありますか?

新しい Enterprise プランまたはセルフサーブの Enterprise プランでは、すべての Enterprise シートに含まれ、追加購入は不要です。古いプランでは、Claude Code を含むシート種別が必要です。

出典: Use Claude Code with your Team or Enterprise plan

Team プランで Computer use は使えますか?

公式ドキュメントの機能一覧では、Computer use は Pro・Max が利用可、Team・Enterprise は利用不可です。Code Review は逆に Team・Enterprise のみです。
