Claude Code のログイン方法の違いとチームでの認証設定

公開: 2026年10月17日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • チームには Claude for Teams または Enterprise が、公式ドキュメントで推奨されています。API 課金なら Claude Console、クラウド利用なら Bedrock などを選びます。
  • 初回は claude を実行するとブラウザでログインします。ブラウザが開かない場合や、コード表示になる場合の対処も公式に書かれています。
  • 管理設定の forceLoginMethod と forceLoginOrgUUID でログイン先を組織に絞れますが、対象外の経路があります。配布前に公式ドキュメントで確認してください。

ログインの流れと選べるアカウント

この記事は、執筆時点(2026年10月)の公式ドキュメントの記載にもとづきます。Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)は、インストール後に claude を実行すると、初回起動時にブラウザが開いてログインを求められます。環境変数 ANTHROPIC_API_KEY を設定済みで、確認でそのキーを承認した場合は、ログインの画面は省略されます。成功すると Login successful と表示されます。

公式ドキュメントによると、使えるアカウントは次のとおりです。

  • Claude Pro または Max:claude.ai のアカウントでログインします。
  • Claude for Teams または Enterprise:管理者から招待された claude.ai アカウントでログインします。
  • Claude Console:Console の認証情報でログインします。先に管理者の招待が必要です。
  • クラウドプロバイダー(Bedrock、Agent Platform、Foundry):claude の実行前に環境変数を設定するか、ログイン画面で 3rd-party platform を選びます(これで起動する対話式のセットアップウィザードは Bedrock と Vertex AI 向けです)。ブラウザでのログインは不要です。
  • クラウドゲートウェイ:自前の Claude apps gateway がある組織では、/login から社内 SSO でサインインします。

やり直すときは /logout を入力します。初回起動時のセットアップ状態もリセットされます。

ブラウザが開かないとき・アカウントを分けるとき

ブラウザが自動で開かない場合は c を押すとログイン URL がコピーされます。サインイン後にログインコードが表示されたら、ターミナルの Paste code here if prompted に貼り付けます。公式ドキュメントによると、これは WSL2、SSH セッション、コンテナで多い現象です。

仕事用と個人用を同時に使うなら、アカウントごとに CLAUDE_CONFIG_DIR で設定ディレクトリを分けます。Bash や Zsh では、次のエイリアスを ~/.bashrc または ~/.zshrc に追加する例が示されています。

alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'

ただし、API キーなしの Console サインインは設定ディレクトリの外に保存されるため、ディレクトリを分けても区別できません。

チームで配る認証方式

公式ドキュメントによると、チーム向けの方式は Claude for Teams または Enterprise、Claude Console、Claude apps gateway、Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry で、このうち Teams または Enterprise がほとんどのチームに推奨されています。

Claude for Teams または Enterprise

Teams はセルフサービスのプランで、管理ツール、SSO、課金管理、サーバー管理設定を備え、小さめのチーム向けです。Enterprise はドメインキャプチャ、ロールベースの権限、コンプライアンス API が加わり、大きな組織向けです。流れは、購読(Enterprise は営業へ問い合わせ)、管理画面でメンバー招待、各メンバーが claude.ai アカウントでログイン、の順です。料金は公式の料金ページで確認してください。

Claude Console

API ベースの課金を希望する組織向けです。ユーザーは Members ページからの一括招待か SSO で追加します。ロールは、Claude Code 用の API キーだけ作れる Claude Code ロールと、あらゆる種類の API キーを作れる Developer ロールから選びます。各ユーザーは招待を承諾し、Claude Code をインストールして Console の認証情報でログインします。

クラウドプロバイダー

各プロバイダーのドキュメントに沿って設定し、環境変数とクラウド認証情報の作り方の案内を利用者に配布します。

API キーなしで Console にサインインする

公式ドキュメントによると、組織が API キーの作成を許していなくても、キーなしで Console にサインインできます。/login で Anthropic Console アカウントを選ぶと方法を聞かれます。Claude Code v2.1.242 以降が必要です。(recommended) の方法は OAuth トークンをプロファイルとして保存し、API キーは作りません。(legacy) の方法は API キーを作って保存します。

次の場合は選択肢が出ず、API キーが作られます。

  • クラウドプロバイダーで実行している場合
  • 設定ファイルに forceLoginOrgUUID がある、または forceLoginMethod が "claudeai" か "console" の場合
  • 管理設定のソースがあるのに Claude Code が読み取れず、ほかに方針を与えるソースもない場合

キーなしでサインインする前に ANTHROPIC_API_KEY を unset します。この方法でサインインすると、マシン上の claude.ai のログインからはサインアウトされます。元に戻すには /logout です。

出典: Authentication

ログイン先を組織に絞る

管理設定に forceLoginMethod と forceLoginOrgUUID を設定すると、claude.ai ログインを特定の組織に限定できます。forceLoginOrgUUID には組織 ID を入れます。公式ドキュメントの例は次のとおりです。

{
  "forceLoginMethod": "claudeai",
  "forceLoginOrgUUID": ["xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"],
  "allowedProviders": ["anthropic", "bedrock"]
}

この例で allowedProviders(Claude Code v2.1.285 以降)は、接続を許すサービスを列挙します。claude.ai の組織にサインインした開発者か Bedrock 向けの設定は起動でき、それ以外のプロバイダーは拒否されます。

注意点は次のとおりです。

  • /login と初回オンボーディングの画面は、方式を事前選択するだけで強制しません。"claudeai" を指定しても Console ログインは完了できます。
  • claude setup-token と /install-github-app は forceLoginMethod しか強制せず、別の組織のトークンを作れます。
  • サーバー管理設定は認証済みのアカウントにしか届かず、最初のログインは誘導できません。デバイス管理ツールで配布し、併用する場合は両方に同じキーを入れます。
  • ANTHROPIC_API_KEY などの環境変数の認証情報は、これらのキーを設定すると起動時にブロックされます。

よくある質問

ブラウザが開かない、またはログインコードが表示されたときはどうしますか?

c を押してログイン URL をコピーし、ブラウザに貼り付けます。コードが表示された場合は、ターミナルの Paste code here if prompted に貼り付けます。WSL2、SSH セッション、コンテナで起きやすいと公式ドキュメントに書かれています。

出典: Authentication

チームで使う場合、どの認証方式が推奨ですか?

公式ドキュメントでは、Claude for Teams または Enterprise がほとんどのチームに推奨されています。API ベースの課金を希望する組織は Claude Console、クラウドを使う組織は各クラウドの設定を選びます。

出典: Authentication

API キーを作らずに Console にサインインできますか?

できます。/login で Console アカウントを選ぶと方法を聞かれます(Claude Code v2.1.242 以降)。ただしクラウドプロバイダー利用時や forceLoginOrgUUID 設定時などは、API キーが作られます。
