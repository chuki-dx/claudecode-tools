Claude Code で AGENTS.md を使う:CLAUDE.md との関係と読み込まれ方

公開: 2026年10月24日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • 公式ドキュメントによると、Claude Code は AGENTS.md を直接読めます。既定では、作業ディレクトリかその上に CLAUDE.md 系のファイルが無いときだけ読みます。
  • CLAUDE.md や CLAUDE.local.md があると、既定では AGENTS.md は読まれません。両方読ませたいときは /config の Project instructions を claude-md-and-agents-md にします。
  • 直接読むには v2.1.277 以降が必要です。読めない環境では、CLAUDE.md に @AGENTS.md を書いて取り込みます。

AGENTS.md は既定でどう読まれるか

公式ドキュメントによると、Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)は AGENTS.md をプロジェクトの指示として読めます。他のコーディングエージェント向けに整えたリポジトリでも、CLAUDE.md の追加、import、設定を足さずに使えます。本記事は執筆時点(2026年10月)の公式ドキュメントに基づきます。

既定の挙動は、リポジトリにあるファイルの組み合わせで決まります。

  • AGENTS.md だけがあり、作業ディレクトリとその上に CLAUDE.md も CLAUDE.local.md も無い場合は、AGENTS.md を読みます。
  • AGENTS.md と、CLAUDE.md または CLAUDE.local.md の両方がある場合は、CLAUDE.md 系のファイルだけを読みます。
  • CLAUDE.md が AGENTS.md を import している場合は、CLAUDE.md を読み、import を通じて AGENTS.md も含まれます。

直接読むには Claude Code v2.1.277 以降が必要です。

読まれる条件と、読まれないファイル

判定の対象になるのは、作業ディレクトリかその上にある CLAUDE.md、.claude/CLAUDE.md、CLAUDE.local.md です。これらがあると AGENTS.md の代わりにそちらが読まれます。~/.claude/CLAUDE.md、組織の managed CLAUDE.md、.claude/rules/ のファイルは判定の対象外で、AGENTS.md と一緒に読み込まれます。

対象が無いとき、セッション開始時に作業ディレクトリとその上の AGENTS.md と .claude/AGENTS.md がすべて読まれます。対話セッションでは no CLAUDE.md found; AGENTS.md loaded: /home/you/repo/AGENTS.md のような行が出るので、読まれたかを確認できます。サブディレクトリの AGENTS.md は、Claude が Read ツールでそこのファイルを開き、そのサブディレクトリに3つの CLAUDE.md 系ファイルのどれも無いときに読まれます。

AGENTS.local.md、AGENTS.override.md、.agents/ ディレクトリ以下は読まれません。

注意点:CLAUDE.local.md も判定の対象です。個人用の未コミットの指示を置こうとして CLAUDE.local.md を足すと、AGENTS.md が読まれなくなります。

/config で読むファイルを切り替える

セッションで /config と入力して設定パネルを開き、Project instructions を次のいずれかにします。

  • claude-md-or-agents-md:既定です。CLAUDE.md を読み、CLAUDE.md も CLAUDE.local.md も無いときは AGENTS.md を読みます。
  • claude-md-and-agents-md:両方を読みます。各ディレクトリで CLAUDE.md が先、AGENTS.md が後です。読み込み済みの AGENTS.md は飛ばすため、二重には読まれません。
  • claude-md:CLAUDE.md だけを読みます。
  • managed-only:起動時は組織の managed CLAUDE.md と auto memory だけです。すべての AGENTS.md は対象外になります。

設定ファイルでも指定できます。pluginConfigs の cc-plugin-agents-md@builtin の下に書きます。読まれるのは ~/.claude/settings.json、--settings ファイル、managed settings で、プロジェクトやローカルの設定ファイルでは無視されます。両方読ませる例です。

{
  "pluginConfigs": {
    "cc-plugin-agents-md@builtin": {
      "options": { "instructionFiles": "claude-md-and-agents-md" }
    }
  }
}

v2.1.285 より前は ID が agents-md@builtin で、cc-plugin-agents-md@builtin は無視されます。古い版も同じファイルを読む環境では agents-md@builtin を使います。変更は次のメッセージから、新しいセッションすべてで有効です。

読めないセッションと、CLAUDE.md との違い

次の場合は CLAUDE.md だけが読まれ、/config に Project instructions も出ません。v2.1.277 より前のバージョン、/plugin で組み込みプラグインを無効にした場合、場合によっては v2.1.276 以前からアップグレードした最初のセッション(次のセッションから読まれます)です。また v2.1.281 より前は、Amazon Bedrock やテレメトリ無効のセッションなどでも CLAUDE.md だけでした。その場合は Claude Code を更新してください。

設定経由で読む AGENTS.md の違い

  • InstructionsLoaded フックは動きません。CLAUDE.md が import や symlink する AGENTS.md では通常どおり動きます。
  • CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD の設定中に --add-dir で足したディレクトリでは、AGENTS.md は読まれません。
  • 作業ディレクトリ外への @path import は、このプロジェクトで外部 import をすでに承認済みの場合だけ読み込まれ、確認は表示されません。

他のツールと1ファイルを共有する

直接読まれない場合も、隣の CLAUDE.md に @AGENTS.md の import を置けば、AGENTS.md を全ツール共通の1ファイルにできます。プロジェクトに CLAUDE.md もあるとき、claude-md にしたとき、直接読めないセッションで使います。Claude 固有の指示は import の下に書きます。

@AGENTS.md

## Claude Code

Use plan mode for changes under `src/billing/`.

Claude 固有の内容が不要なら、symlink でも構いません。

ln -s AGENTS.md CLAUDE.md

symlink を選ぶ前に、次の点を確認してください。

  • Edit と Write ツールは symlink 越しの書き込みを拒否し、リンク先の AGENTS.md を編集するよう案内します。
  • Windows で作業する人や clone する人がいるなら、@AGENTS.md の import を使います。symlink の作成に Administrator 権限か Developer Mode が必要で、core.symlinks が有効でないと、Git が1行だけの CLAUDE.md を作るためです。

どちらでも、次のセッションで /context を実行し、Memory files に CLAUDE.md が出ることを確認します。

よくある質問

すでに @AGENTS.md を書いた CLAUDE.md がある場合、消すべきですか。

公式ドキュメントによると、残しても構いません。Project instructions がどの値でも、AGENTS.md が二重に読まれることはありません。他に内容が無ければ削除できますが、AGENTS.md を直接読めないセッションがあるなら残します。

出典: How Claude remembers your project

CLAUDE.md と AGENTS.md の両方を読ませるにはどうしますか。

/config で Project instructions を claude-md-and-agents-md にします。設定ファイルの場合は pluginConfigs の cc-plugin-agents-md@builtin に instructionFiles を指定します。各ディレクトリで CLAUDE.md が先、AGENTS.md が後に読まれます。

出典: How Claude remembers your project

AGENTS.md が読まれないときは、何を確認しますか。

作業ディレクトリかその上に CLAUDE.md、.claude/CLAUDE.md、CLAUDE.local.md が無いかを確認します。あれば既定では AGENTS.md は読まれません。次に Claude Code が v2.1.277 以降か、組み込みプラグインを /plugin で無効にしていないかを確認します。直接読めない場合は @AGENTS.md の import が使えます。
