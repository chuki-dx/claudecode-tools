Claude Code を社内で試す前に確認すること(プラン・PC・ネットワーク・社内ルール)

公開: 2026年10月14日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントにもとづきます

結論

  • インストールの前にプラン・PC 環境・ネットワーク・社内ルールの4つを確認しておくと、「使えなかった」「通らなかった」「規程に引っかかった」という手戻りを減らせます。
  • Claude Code は無料プランでは使えません。Windows では管理者権限なしで入れられますが、社内のインストール手続きは別に確認が要ります。
  • 社内ルールに AI ツールの記載がなければ、使う範囲を決めて上司や担当者に一度相談し、その記録を残しておきます。

なぜ先に確認するのか

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)を社内で試すとき、止まる理由の多くは技術の難しさではありません。契約したプランでは使えなかった、社内のプロキシで通信が通らなかった、あとから規程に合わないと分かった、といった、事前に確認できることです。

個人で使うツールなら「まず入れてみる」でも困りません。ただ、業務で使う AI ツールは、あとから問題が見つかると「なぜ確認せずに使ったのか」という話になりがちです。先に確認しておけば、上司に相談するときにも「プラン・環境・ルールは確認済みです」と伝えられます。

以下は、執筆時点(2026年10月)の公式ドキュメントにもとづくチェックリストです。製品の仕様は変わるので、試す直前にリンク先で最新の情報を確かめてください。

1. プラン(アカウント)の確認

  • Claude Code が使えるプランか: 公式ドキュメントでは、Pro・Max・Team・Enterprise、または Console(API 用の管理画面)のアカウントが必要とされています。claude.ai の無料プランには Claude Code が含まれていません。
  • 個人で契約するか、法人で契約するか: 個人の Pro で小さく試すのか、最初から Team などの法人向けプランにするのかを決めます。法人向けプランには管理機能があり、データの扱いも個人向けとは異なります。
  • 使える国・地域か: Anthropic がサービスを提供している国・地域で使う必要があります。

個人契約で業務データを扱ってよいかは、会社によって判断が分かれます。迷ったら、後半の「社内ルールの確認」を先に済ませてからプランを決めると、手戻りがありません。

2. PC 環境の確認

項目公式ドキュメントの記載(執筆時点)
OSWindows 10 1809 以上、または Windows Server 2019 以上。macOS は 13.0 以上
メモリ4GB 以上
インストールPowerShell または コマンドプロンプトからインストール用のコマンドを実行。管理者として実行する必要はない。WinGet でも入れられる
Git for Windows任意。入れると、コマンドの実行に Git Bash が使われる。入れない場合は PowerShell で実行される
更新推奨の方法で入れた場合は自動で更新される。更新を遅らせる stable のチャネルを選んだり、自動更新を止めたりもできる

中小企業の情シスにとって大きいのは、管理者権限なしで入れられる点です。ただし、権限が要らないことと、社内でインストールしてよいことは別の話です。この点は社内ルールの項目で確認します。

社内で更新のタイミングをそろえたい場合は、試す段階から更新の方法を決めておくと、利用者ごとにバージョンがばらつくのを防げます。

3. ネットワークの確認

Claude Code はインターネット接続が必要です。社内にプロキシやファイアウォールがある場合は、通信先の許可が要ることがあります。公式ドキュメントでは、許可が必要な通信先として次のようなものが挙げられています(一部)。

  • api.anthropic.com(Claude の API)
  • claude.ai と claude.com(claude.ai のアカウントでのログイン)
  • platform.claude.com(Console のアカウントでのログインなど)
  • downloads.claude.ai(インストールと自動更新)

プロキシを通す場合は、環境変数 HTTPS_PROXY にプロキシの URL を設定する方法が案内されています。通信先の一覧は変わることがあるので、許可を依頼する前に公式ドキュメントの最新の表を確認してください。

UTM(統合脅威管理)機器やプロキシの設定を外部の業者に任せている場合は、許可の反映に日数がかかることがあります。試したい日が決まっているなら、この項目は早めに動いておくと安心です。

4. 社内ルールの確認

ここは製品の仕様ではなく、自社のルールの確認です。情シス自身がルールを作る立場のこともあれば、総務や情報管理の担当に確認する立場のこともあります。

  • 情報セキュリティ規程で、外部の AI サービスの利用が認められているか
  • AI に入力してよい情報の範囲: たとえば、業務の手順はよいが、顧客名や個人情報は入れない、といった線引き
  • 会話データの扱い: 公式ドキュメントでは、個人向けプラン(Free・Pro・Max)は会話をモデルの改善に使うかどうかを利用者が設定で選ぶ形、Team・Enterprise・API などの法人向けの条件では、原則として学習に使わないと説明されています。業務で使うなら、試す前に設定を確認します。
  • ソフトウェアのインストール手続き: 管理者権限が不要でも、社内で申請が必要な場合があります。
  • 費用の負担者: 個人の立て替えか、部署の予算か

規程に AI ツールについての記載がない会社も少なくありません。その場合は「書いていないから使ってよい」と判断せず、「この範囲で試したい」と上司や情報管理の担当に一度相談しておくのがおすすめです。相談した記録が残っていれば、あとで説明を求められたときにも困りません。

5. インストール後の確認

  1. ターミナルで claude --version を実行し、バージョン番号が表示されることを確かめます。
  2. claude doctor を実行し、インストールや設定ファイルの問題が出ていないかを確かめます。
  3. 試すための空のフォルダを作り、その中で claude を起動してログインします。

3つ目は小さなことに見えますが、大事な点です。Claude Code は起動したフォルダの中で作業します。業務の大事なファイルがあるフォルダでいきなり起動せず、空のフォルダから始めると安心です。

試すフォルダができたら、最初に2つのファイルを用意しておくと、そのあとの作業が落ち着きます。1つは、Claude Code が起動時に読む説明書きのファイル CLAUDE.md です。もう1つは、読ませないファイルや実行させないコマンドを決める .claude/settings.json です。どちらも、このサイトの CLAUDE.md テンプレート生成 と 権限設定(settings.json)ジェネレーター で、選ぶだけで下書きを作れます。

よくある質問

個人の Pro で試して、あとから法人プランに移ってもよいですか

進め方としてはありえます。ただ、個人契約で業務データを扱ってよいかは社内ルールしだいです。試す範囲を「架空のデータだけ」などに決め、上司の了解を得てから始めると、移るときの説明もしやすくなります。

管理者権限が無い PC でも入れられますか

公式ドキュメントでは、Windows のインストールは管理者として実行する必要がないとされています。ただし、社内でソフトウェアのインストールに申請が要る場合は、その手続きを先に確認してください。

プロキシがある環境で、ログインの画面から先に進みません

許可が必要な通信先が通っていない可能性があります。公式ドキュメントのネットワーク構成のページで通信先とプロキシの設定方法を確認し、claude doctor の結果も合わせて担当者に伝えると、話が早く進みます。

最初の設定ファイルを作る

試すフォルダに置く CLAUDE.md は CLAUDE.md テンプレート生成、.claude/settings.json は 権限設定(settings.json)ジェネレーター で作れます。どちらもブラウザの中だけで動き、入力した内容は送信しません。
