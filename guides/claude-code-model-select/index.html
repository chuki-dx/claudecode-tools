Claude Code のモデルの選び方と切り替え方(/model と設定)

公開: 2026年10月15日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • モデルは sonnet・opus・haiku などのエイリアスかモデル名で指定します。公式ドキュメントでは、日常のコーディングは sonnet、複雑な推論は opus、簡単な作業は haiku という位置づけです。
  • 切り替えはセッション中なら /model、起動時なら --model、常用するなら設定ファイルの model です。/model は Enter で選ぶと既定として保存されます。
  • 社内に配る前に、エイリアスが更新されること、Fable は利用クレジットに請求される場合があること、管理者設定が優先されることを確認してください。

Claude Code で指定できるモデルとエイリアス

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)では、model 設定にモデルエイリアス(バージョン番号を覚えずに使える短い名前)かモデル名を指定できます。執筆時点(2026年10月)の公式ドキュメントによると、モデル名の形式は提供元ごとに異なります。

  • Anthropic API: フルのモデル名
  • Amazon Bedrock: 推論プロファイルの ARN
  • Microsoft Foundry: デプロイ名
  • Google Cloud の Agent Platform: バージョン名

なお ANTHROPIC_BASE_URL は送信先を変えるもので、どのモデルが答えるかは変えません。作業別のモデルの向き不向きは、公式ドキュメントが案内するブログ記事で確認してください。

出典: Model configuration

用途別のエイリアスの選び方

  • sonnet: 日常的なコーディング向けの最新 Sonnet
  • opus: 複雑な推論向けの最新 Opus
  • haiku: 簡単なタスク向けの、高速で効率的なモデル
  • opusplan: プランモードでは opus、実行では sonnet を使う特別なモード
  • sonnet[1m]・opus[1m]: 1 million token のコンテキストウィンドウで、長いセッション向け。モデルがすでに標準で 1M のウィンドウを持つ場合は効果がありません
  • fable: 最も難しく長時間かかるタスク向け。best は Fable が使えるならその Fable、使えなければ opus と同じモデルです
  • default: 上書きを解除してアカウントの既定に戻す特別な値で、エイリアスそのものではありません

提供元によって解決先が違います

opus・sonnet・haiku は、Anthropic API では最新版に、他の提供元では以前のバージョンに解決されることがあります。たとえば Amazon Bedrock では Opus 5.5・Sonnet 4.5・Haiku 4.5、Microsoft Foundry では Opus 4.6・Sonnet 4.5・Haiku 4.5 です。

エイリアスは時間とともに更新されます。固定したい場合は claude-opus-5-5 のようなフルのモデル名か、ANTHROPIC_DEFAULT_OPUS_MODEL などの環境変数を使います。新しいモデルには Claude Code 側のバージョン条件もあり、たとえば Sonnet 5.5 は v2.1.284 以降が必要です。古い場合は claude update で更新します。

出典: Model configuration

/model・--model・設定ファイルでの切り替え方

公式ドキュメントは、次の方法を優先度の順に挙げています。

  1. セッション中: /model <alias|name> で即時に切り替え、引数なしの /model でピッカー(選択画面)を開く
  2. 起動時: claude --model <alias|name>
  3. 環境変数: ANTHROPIC_MODEL=<alias|name>
  4. 設定ファイルの model フィールドで恒久的に指定
  5. 新規セッションの既定: ANTHROPIC_DEFAULT_MODEL=<alias|name>(Claude Code v2.1.236 以降)
claude --model opus
/model sonnet
{
    "permissions": {
        "allow": ["Bash(npm run lint)"]
    },
    "model": "opus"
}

ピッカーでは Enter で切り替えて既定として保存し、s でこのセッションだけ切り替えます。/model <name> と直接入力した場合は Enter と同じ動きで、既定として保存されます。--model と ANTHROPIC_MODEL は起動したセッションにだけ効くため、複数のターミナルで別々のモデルを使うなら、それぞれ --model で起動します。

思ったモデルで始まらないときの確認

現在のモデルは、ステータスライン(設定している場合)か /status で確認できます。次の新規セッションが違うモデルで始まる主な原因として、公式ドキュメントは次を挙げています。

  • このセッションだけの選択だった(s、--model、非対話モードの /model)
  • 優先度の高い設定がある(プロジェクトや管理設定の model、シェルの ANTHROPIC_MODEL、管理者が上書きを有効にした組織の既定)
  • ~/.claude/settings.json に書き込めず、保存できなかった
  • セッションを再開した(claude --resume や --continue は通常、そのときのモデルを保持します)

また、/model での切り替えは、メインの会話のモデルを引き継ぐサブエージェントにも及びます。

Fable を使うときの注意

公式ドキュメントによると、Claude Fable 5.1 と Claude Fable 5 は Claude Code で最も高性能なモデルで、一度に終わらない大きなタスク向けです。どのプラン・提供元でもアカウント種別の既定ではないため、明示的に選びます。Fable 5.1 は /model fable か claude --model fable で選べます(Claude apps gateway のセッションではエイリアスが Fable 5 に解決されるため、代わりに /model claude-fable-5-1 を使います)。Claude Code v2.1.257 以降が必要です。

プランや席の種別によっては、Fable の利用がプランに含まれる上限ではなく利用クレジットに請求されます。その場合、ピッカーの Fable 行に「Requires usage credits」と出ます。対話セッションでは請求前に同意プロンプトが出ます(組織請求の Enterprise プランのメンバーには出ません)が、-p の非対話モードでは確認なしで請求されます。自動実行に使う場合は、先に公式ドキュメントで確認してください。

管理者が制限や既定を決めるとき

公式ドキュメントでは、管理対象設定の availableModels で、利用者が選べるモデルを制限できます。Anthropic API と Claude Platform on AWS では、ファミリーエイリアスが許可リスト外のモデルを指す場合、リストが許可する同じファミリーの最新版に置き換えられます。それ以外の許可リスト外のモデルは /model ではエラーになり、--model などで指定した値は起動時に置き換えられて、既定モデルで始まります。

{
  "availableModels": ["sonnet", "haiku"]
}

接頭辞マッチの既定では、availableModels だけだと Default は許可リスト外のモデルになりえます。その場合は enforceAvailableModels を併用します(v2.1.175 以降)。また model 設定は初期選択であって強制ではなく、利用者は /model で Default を選べます。

Enterprise プランでは、管理者が管理コンソールで組織の既定モデルを設定でき、個別のモデルを無効にすることもできます。ただし Haiku は無効にできません。組織の既定は、上書きを有効にした場合に限り、ユーザー・プロジェクト・ローカル設定の model より優先されます。

よくある質問

/model で選んだモデルは次回の起動でも使われますか?

ピッカーで Enter を押すか /model <name> と直接入力すると、既定として保存されます。s で選んだ場合や --model での起動は、そのセッションだけです。プロジェクト設定や管理設定、ANTHROPIC_MODEL など優先度の高い指定があると、保存した選択より優先されます。

出典: Model configuration

複数のターミナルで別々のモデルを同時に使うには?

公式ドキュメントでは、/model で切り替えるのではなく、それぞれのターミナルを自分の --model フラグ付きで起動するよう案内しています。--model は起動したセッションにだけ適用されます。

出典: Model configuration

モデルのバージョンを固定するにはどうしますか?

エイリアスは推奨バージョンを指し、時間とともに更新されます。固定するには claude-opus-5-5 のようなフルのモデル名を使うか、ANTHROPIC_DEFAULT_OPUS_MODEL のような対応する環境変数を設定します。
