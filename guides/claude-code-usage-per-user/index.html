Claude Code のユーザー別コストを CSV で出す:Team・Enterprise の支出レポートと API・クラウドの場合

公開: 2026年11月26日 ・ 中小DXラボ ・ 内容は執筆時点(2026年11月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • Team・Enterprise の分析画面にある支出レポートは、ユーザー別・モデル別の CSV として出力できます(更新は日次)。ただし対象は使用クレジットの支出で、席の枠内の利用は含まれません。
  • 支出レポートを見られるのは、Team の Owner・Primary Owner と、Enterprise の Owner・Primary Owner です。Enterprise の Admin は Spend 以外の分析を見られます。
  • API 利用(Console)とクラウド経由では確認する場所が別です。クラウド経由は分析画面の対象外なので、OpenTelemetry などで自前に集計します。

契約形態ごとに、ユーザー別の数字を見る場所が違う

Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)のユーザー別の利用量やコストは、組織の利用形態によって見る場所が変わります。公式ドキュメントによると、形態は Claude for Teams・Enterprise、Claude Console(API)、クラウド経由(Amazon Bedrock、Google Cloud's Agent Platform、Microsoft Foundry)の3つです。

Teams・Enterprise では利用が各メンバーの席の枠から引かれ、Console とクラウドではトークン単位で組織に課金されます。サインイン方法が混在する場合は、各開発者が認証に使った方法で計測されます。

  • Teams・Enterprise:組織の分析画面の支出レポート(CSV 出力あり)。Enterprise ではさらに Enterprise Analytics API
  • Console(API):Console のダッシュボードと Claude Code Analytics API
  • クラウド経由:OpenTelemetry か LLM gateway

OpenTelemetry は全ての構成で使え、ユーザー別のトークン・コストを自社の監視基盤へほぼリアルタイムで流せる唯一の選択肢とされています。なお、本記事は執筆時点(2026年11月)の公式ドキュメントとヘルプセンターの記載に基づきます。画面名やボタン名は変わることがあるため、実際の画面で確認してください。

Team・Enterprise:支出レポートを CSV で出す手順

公式ヘルプセンターによると、使用状況の分析は Team プランの Owner と Primary Owner、Enterprise プランの Owner・Primary Owner・Admin が使えます。ただし Enterprise の Admin が見られるのは Spend を除く分析です。

支出レポートは、選んだ期間について、ユーザー別・モデル別にトークン使用量と推定支出を確認できる CSV です。出力の手順は次のとおりです。

  1. Settings > Analytics を開きます。
  2. How much is Claude costing? の節までスクロールします。
  3. 「Export spend report」ボタンをクリックします。
  4. 期間を MTD、Last Month、Last 90 Days、Custom から選びます。
  5. Custom の場合は開始日と終了日を選びます。最大90日さかのぼれ、最新のデータは前日分です。
  6. 「Download」をクリックします。

CSV の中身と、含まれない利用・更新の頻度

公式ヘルプセンターによると、CSV の1行は特定の人による特定モデルの利用で、支出は選んだ期間全体で合計されます。列は次のとおりです。

  • ユーザーのメールアドレス
  • Account UUID
  • Product(Chat、Claude Code、Cowork、Office Agents など)
  • Model と model family
  • total_requests:API 呼び出しの回数
  • total_prompt_tokens:各リクエストの入力側で消費したトークン数
  • total_completion_tokens:Claude が生成したトークン数(拡張思考のトークンを含む)
  • total_net_spend_usd:割引・クレジット・交渉レートを適用した後の費用(USD)
  • total_gross_spend_usd:割引やクレジットを適用する前の費用(USD)

席の枠内の利用は含まれない

席ベースの Enterprise プランでは、支出データが対象にするのは席の枠を超えた分の支出です。席ベースの Enterprise プランでは、組織が使用クレジットを有効にしている場合だけ支出レポートが表示され、席の枠内の利用は含まれません。使用量ベースの Enterprise プランでは、組織の全利用が含まれます。Claude Code の公式ドキュメントでも、席の枠内の利用はドルで計測されないと説明されています。

更新の頻度と請求との関係

データは毎日更新され、1日の遅れがあります。ヘルプセンターでは、エクスポートした支出レポートは請求書とおおむね一致するはずとされていますが、プロジェクトタグでグループ化した支出は一致しない場合があります。また、以前は Claude Code にまとめられていた Code Review やセキュリティ機能などの一部は、別の項目として表示されます。

Enterprise の Analytics API と、ダッシュボードのそのほかの CSV

公式ドキュメントによると、Enterprise プランでは Enterprise Analytics API が、Claude Code を含む Claude の各サービスについて、ユーザー別の利用とコストのレポートを返します。Teams プランでは使えないため、Teams では前の節の支出レポート CSV を使います。

キーは Primary Owner が read:analytics スコープで作成します。ヘルプセンターによると、Analytics API の有効化とキー作成ができるのは Primary Owner だけで、Owner や Admin には設定画面にそもそも表示されません。これは権限エラーではなく想定どおりの動きです。

Claude Code の分析ダッシュボードにも CSV 出力があります。Leaderboard の「Export all users」で全ユーザーの貢献データ(PR とコード行数)が出ますが、これはコストの CSV ではありません。コストは支出レポートで確認します。

Console(API)・クラウド経由の場合の確認先

Console(API)の場合

公式ドキュメントによると、Console の Claude Code 用ダッシュボードで、メンバーごとの支出と受け入れられた行数を確認できます。表示には UsageView 権限が必要で、Developer、Billing、Admin、Owner、Primary Owner のロールが持っています。チームインサイトの表は、既定では直近30日の Members、Spend、Lines accepted を表示します。金額は分析用の推定値で、実際の費用は Cost ページで確認します。

日次のユーザー別指標をプログラムで取るには、Admin API key を使って Claude Code Analytics API を呼びます。ダッシュボードの CSV 出力については出典に記載がないため、公式ドキュメントで確認してください。

クラウド経由の場合

Amazon Bedrock などでは、Claude Code からクラウド側のメトリクスが Anthropic に送られないため、分析ダッシュボードと Claude Code Analytics API の対象外です。ユーザー別に集計する選択肢は3つあります。

  • OpenTelemetry:各開発者のマシンから自社の監視基盤へ出し、ユーザー別のトークン数・コスト・ツール活動を得ます。
  • Claude apps gateway:自社で運用し、ユーザー別の利用の帰属、OTLP メトリクス、ユーザー別の支出上限を提供します。
  • LLM gateway:通信をすべてプロキシ経由にし、キー単位で支出を追跡します。例の LiteLLM はオープンソースで、Anthropic とは無関係であり、セキュリティ監査はされていないとされています。

よくある質問

Enterprise の Admin は支出レポートの CSV を出せますか?

公式ヘルプセンターによると、Enterprise の Admin が見られるのは Spend を除く分析です。支出の確認は Owner か Primary Owner に依頼してください。

出典: View usage analytics for Team and Enterprise plans

CSV に席の枠内の利用は入りますか?

入りません。席ベースの Enterprise プランでは、使用クレジットを有効にした場合に、席の枠を超えた支出だけが反映されます。

出典: View usage analytics for Team and Enterprise plans

Bedrock などクラウド経由でも、ユーザー別のコストは分かりますか?

分析ダッシュボードの対象外です。公式ドキュメントでは、OpenTelemetry、Claude apps gateway、LLM gateway の3つの方法が挙げられています。
