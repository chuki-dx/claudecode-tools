Claude Code の会話データは学習に使われるか:保存期間と設定の確認先

公開: 2026年10月15日 ・ 中小DXラボ ・ 内容は執筆時点(2026年10月)の公式ドキュメントなどの出典にもとづきます(各節の末尾に出典を記載)

結論

  • 個人向けプラン(Free・Pro・Max)では、データを将来のモデル改善に使うかを選ぶ設定があり、オンの間は Claude Code(Anthropic 社が提供する、ターミナルで動く AI コーディングエージェント)の利用分も学習に使われます。
  • 商用プラン(Team・Enterprise・API など)では、商用条件の下で送られたコードやプロンプトは、顧客がモデル改善への提供を選んだ場合を除き、生成モデルの学習に使われません。
  • 保存期間は、個人向けで許可ありなら5年、許可なしなら30日、商用の標準は30日です。ゼロデータ保持は Enterprise の適格アカウントに別途有効化されるもので、標準では含まれません。

学習に使われるかはプランで決まります

本記事は、執筆時点(2026年10月)の公式ドキュメント「Data usage」の内容を整理したものです。実機で試した結果ではありません。

個人向け(Free・Pro・Max)

公式ドキュメントによると、Free、Pro、Max のアカウントでは、データを将来の Claude モデルの改善に使ってよいかを利用者が選べます。この設定がオンの場合、これらのアカウントで Claude Code を使ったときのデータも、新しいモデルの学習に使われます。

商用(Team・Enterprise・API など)

Team と Enterprise、API、サードパーティのプラットフォーム、Claude Gov は商用の扱いです。公式ドキュメントでは、商用条件の下で Claude Code に送られたコードやプロンプトで Anthropic が生成モデルを学習することはないとされています。ただし、顧客自身がモデル改善のためにデータを提供すると選んだ場合は例外です。

例外の例が Development Partner Program です。組織の管理者が明示的に参加を選ぶ仕組みで、Anthropic 直接の API だけが対象です。Amazon Bedrock や Google Cloud の Agent Platform の利用者は対象外です。

保存期間:個人向けは5年か30日、商用は標準30日

公式ドキュメントでは、Anthropic は Claude Code のデータをアカウントの種類と設定に応じて保存するとされています。

個人向け(Free・Pro・Max)

  • モデル改善への利用を許可している場合:5年間(モデル開発と安全性向上のため)
  • 許可していない場合:30日間
  • プライバシー設定はいつでも変更できます。

商用(Team・Enterprise・API)

  • 標準:30日間
  • ゼロデータ保持:Claude for Enterprise の Claude Code で、適格なアカウントが対象です。標準の Enterprise プランには含まれず、アカウントチームが適格性を確認したうえで組織ごとに有効化されます。
  • ローカルキャッシュ:Claude Code のクライアントは、セッションの記録を ~/.claude/projects/ に平文で、標準では30日間保存します。セッション再開のためで、期間は cleanupPeriodDays で調整できます。Claude Desktop や Cowork で開始または直近に続けたセッションの記録は、標準ではこの期限の対象外です。

クラウドセッションは個別にいつでも削除でき、削除するとセッションのイベントデータが完全に削除されます。ローカルに平文で残る点は、端末の管理方針を考える材料になります。

出典: Data usage

設定の確認先と、社内で確認する順番

個人向けのプライバシー設定は、公式ドキュメントにリンクされている設定ページで、いつでも変更できます。詳しい条件は、商用向け(Team、Enterprise、API)の Commercial Terms of Service、個人向け(Free、Pro、Max)の Consumer Terms、Privacy Policy、Privacy Center で確認するよう案内されています。

  1. 利用するアカウントのプラン(個人向けか商用か)を確認する。
  2. 個人向けなら、モデル改善への利用の設定を確認する。
  3. 商用なら、Development Partner Program に組織として参加していないかを管理者に確認する。
  4. ゼロデータ保持が必要なら、アカウントチームに適格性を相談する。

フィードバックやアンケートで送られるデータ

学習の設定とは別に、利用者の操作や設定で送られるデータがあります。

  • /feedback:会話履歴(コードを含む)のコピーが Anthropic に送られます。ただし Amazon Bedrock や Google Cloud の Agent Platform などのサードパーティのプロバイダーを使う場合や、Anthropic の認証情報を設定していない場合は、Anthropic には送られず ~/.claude/feedback-bundles/ にローカルの書庫として書き出されます。/bug と /share も同じ経路で、これらで共有した記録は5年間保存されます。送信前に、現在のセッションだけ(既定)か、同じプロジェクトの過去24時間または7日分も含めるかを選べます。止めるには DISABLE_FEEDBACK_COMMAND=1 を設定します。
  • セッション品質アンケート:評価だけが記録されます。続く「セッション記録を見てよいか」の確認で「Yes」を選んだときだけ、会話記録がアップロードされ、最長6か月保存されます(Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、サインイン済みの Claude apps gateway のセッションでは、アップロードされず ~/.claude/feedback-bundles/ にローカルの書庫として書き出されます)。既知の API キーやトークンのパターンは伏せられますが、ソースコードやファイルの内容はそのまま送られます。回答は学習の設定に影響せず、モデルの学習にも使えないとされています。無効化は CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1 です。
  • テレメトリ(利用状況の指標):遅延、信頼性、利用パターンが送られ、コード、プロンプト、ファイルパスは含まれません。止めるには DISABLE_TELEMETRY=1 を設定します。

Amazon Bedrock、Microsoft Foundry などを使う場合は、テレメトリ、エラー報告、バグ報告は既定で無効ですが、セッション品質アンケートは例外で動きます。CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC を設定すると、アンケートを含む非必須の通信をまとめて止められます。

ゼロデータ保持(ZDR)の範囲と注意点

公式ドキュメントによると、ZDR を有効にすると、Claude Code のセッションで生成されるプロンプトとモデルの応答はリアルタイムで処理され、応答が返された後は Anthropic に保存されません。法令遵守や悪用対策に必要な場合は例外です。

  • 対象は Claude for Enterprise の適格アカウントです。標準プランには含まれず、管理画面からは有効化できません。営業窓口か Anthropic のアカウントチームに連絡します。
  • 有効化は組織ごとです。同じアカウントで新しく作った組織には自動で適用されません。
  • ZDR の組織にログインしたセッションだけが対象です。個人アカウントや別組織の API キーで使った分は対象外で、forceLoginMethod と forceLoginOrgUUID の管理設定でログインを制限できます。
  • Anthropic の直接のプラットフォームだけが対象です。Amazon Bedrock などは各プラットフォームのポリシーを確認します。
  • 対象外:claude.ai のチャット、Cowork、Claude Code Analytics、ユーザーと席の管理データ、サードパーティ連携。
  • 自動で無効になる機能:クラウドセッション、Claude Tag、Artifacts、/feedback・/bug・/share、Remote Control。

ポリシー違反としてフラグが付いたセッションは、入出力が最長2年保持されることがあります。

よくある質問

個人の Pro プランで Claude Code を使うと、会話は学習に使われますか?

データをモデル改善に使うかの設定がオンの場合は、Claude Code の利用分も含めて新しいモデルの学習に使われます。設定は公式ドキュメントにリンクされたプライバシー設定のページでいつでも変更できます。

出典: Data usage

学習を許可しない場合、データはどれくらい保存されますか?

個人向けプランでは30日間です。許可している場合は5年間です。商用プランの標準は30日間で、ゼロデータ保持は適格な Enterprise アカウントに別途有効化されます。

出典: Data usage

Enterprise プランに入れば、ゼロデータ保持は使えますか?

標準では使えません。標準の Enterprise プランには含まれず、管理画面からも有効化できません。適格性の確認後、Anthropic が組織ごとに有効化します。
