What skills (SKILL.md) are

A skill is a procedure and output format that you give a name so it can be invoked. Place it at .claude/skills/<skill-name>/SKILL.md, and Claude Code uses it on its own when a request matches the description. You can also call it by name, like /skill-name. CLAUDE.md is read every time, whereas a skill is a playbook used when that particular task is requested.

The format this tool outputs

The section enclosed by --- at the top (frontmatter) contains only two fields, name and description. This is the same form that Windows 11 and Claude Code 2.1.296 loaded for all five skills in our internal standard set, and that also passed claude plugin validate .claude/skills (October 2026).

  • The official docs say all frontmatter fields are optional, that writing description is recommended, and that if you omit name, the folder name becomes the invocation name (as of writing).
  • The description is reportedly cut off at 1,536 characters when combined with when_to_use in the listing. Put the most important uses first.
  • Skill names are limited to lowercase letters, digits, and hyphens, the same as the in-house standard set. synced and anthropic-skills are reserved in the official docs, so you can't use them.
  • If the description contains YAML-significant syntax such as ": ", the frontmatter can become unreadable. Only in that case does this tool wrap the description in ".
  • I haven't included allowed-tools, which lets tools run without confirmation, because the official docs say it takes effect regardless of the project trust check.

How to use

  1. Fill in the fields above, or load the example and edit it, then click "Save SKILL.md".
  2. Create a folder at the location shown (for example, .claude/skills/minutes-summary/) and put the saved SKILL.md in it.
  3. In that folder, run claude plugin validate .claude/skills, then ask "List the names of the skills available" and check that your skill appears in the list.
  4. Run it once with fictional data and check that the output matches the expected format before you distribute it.

FAQ

My skill doesn't appear in the list

Check the location of .claude/skills/<name>/SKILL.md and that the first line starts with ---, then run claude plugin validate .claude/skills. Other common pitfalls are covered in the Troubleshooting Cheat Sheet.

Skills aren't being used automatically

Sometimes the wording in description doesn't match the way people phrase their requests. Add the words your users normally use to the "when to use" part. You can also call the skill directly with /skill-name.

Is the content I enter sent anywhere?

No, it is not sent. This page runs on HTML and JavaScript only, and generation happens inside your browser. To count page views, only the URL of the page you opened is sent to the operator's server (no cookies or external analytics services are used. Details).
