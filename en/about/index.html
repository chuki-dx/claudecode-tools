Purpose of this site

This site helps IT admins and in-house SEs at small and midsize companies try Claude Code (an AI coding agent from Anthropic that runs in the terminal) safely, roll it out internally, and explain its budget. It offers free tools that run entirely in your browser, along with guides that explain the background.

What you enter in the tools is not sent externally; it is processed in your browser.

View count tracking

To learn which pages are read and how often, opening a page sends only the following information to the operator's server (jpexam.ai-income.jp). No external analytics service is used.

  • URL of the opened page (path only)
  • The domain name of the site you were on just before coming to this one (such as a search engine; the page URL is not sent)

This site does not use cookies and stores nothing in your browser. Anything you enter in the tools is not sent anywhere. If your browser has tracking protection enabled (Do Not Track or Global Privacy Control), nothing is sent.

The destination server records standard access logs (IP address, date and time, browser type, and so on). Standard access logs are used to investigate failures and respond to unauthorized access, and the oldest entries are deleted once the storage limit is reached. For the records used to count page views, only a value with the end of the IP address masked (for IPv4, the last number set to 0) is kept, and it is deleted after 14 days. The only data kept in aggregate is daily page views and visitor counts, and page views by page and by referrer domain. None of it is used for advertising.

How the listed content is verified
