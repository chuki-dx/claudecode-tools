Claude Code Login Methods and Authentication Setup for Teams

Published: October 17, 2026 ・ Chuki DX Lab ・ Content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section

Key takeaways

  • The official docs recommend Claude for Teams or Enterprise for teams. For API billing, choose the Claude Console; for cloud usage, choose something like Bedrock.
  • On first run, claude opens a browser for login. The official docs also explain what to do if the browser doesn't open or if a code is shown instead.
  • You can restrict the login destination to your organization with the managed settings forceLoginMethod and forceLoginOrgUUID, but some paths are not covered. Check the official docs before you distribute.

The login flow and the accounts you can choose

This article is based on the official docs as of writing (October 2026). After you install Claude Code (an AI coding agent from Anthropic that runs in the terminal) and run claude, a browser opens on first launch and asks you to log in. If you have already set the environment variable ANTHROPIC_API_KEY and approved that key at the prompt, the login screen is skipped. On success, Login successful is displayed.

According to the official docs, the following accounts can be used.

  • Claude Pro or Max: Sign in with your claude.ai account.
  • Claude for Teams or Enterprise: Log in with the claude.ai account your admin invited you with.
  • Claude Console: Sign in with your Console credentials. An administrator must invite you first.
  • Cloud providers (Bedrock, Agent Platform, Foundry): set the environment variables before running claude, or choose 3rd-party platform on the login screen (the interactive setup wizard this launches is for Bedrock and Vertex AI). No browser login is needed.
  • Cloud gateway: organizations with their own Claude apps gateway sign in through company SSO from /login.

To start over, enter /logout. This also resets the first-launch setup state.

When the browser doesn't open, and when you need to separate accounts

If the browser doesn't open automatically, press c to copy the login URL. After you sign in, when a login code is displayed, paste it at the Paste code here if prompted prompt in the terminal. According to the official docs, this is common in WSL2, SSH sessions, and containers.

If you use work and personal accounts at the same time, separate the configuration directories per account with CLAUDE_CONFIG_DIR. For Bash or Zsh, the docs show an example of adding the following aliases to ~/.bashrc or ~/.zshrc.

alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'

However, a Console sign-in without an API key is stored outside the configuration directory, so splitting directories does not keep them separate.

Authentication methods to distribute to the team

According to the official docs, the methods for teams are Claude for Teams or Enterprise, Claude Console, Claude apps gateway, Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Of these, Teams or Enterprise is recommended for most teams.

Claude for Teams or Enterprise

Teams is a self-service plan with admin tools, SSO, billing management, and server-managed settings, aimed at smaller teams. Enterprise adds domain capture, role-based permissions, and a compliance API, and is aimed at larger organizations. The flow is: subscribe (for Enterprise, contact sales), invite members from the admin console, and each member signs in with their claude.ai account. Check the official pricing page for prices.

Claude Console

This is for organizations that want API-based billing. Add users through bulk invitations from the Members page or through SSO. You choose between the Claude Code role, which can only create API keys for Claude Code, and the Developer role, which can create any kind of API key. Each user accepts the invitation, installs Claude Code, and logs in with their Console credentials.

Cloud providers

Configure each provider following its own documentation, and distribute instructions to users on how to set up environment variables and cloud credentials.

Sign in to the Console without an API key

According to the official docs, you can sign in to the Console without a key even if your organization doesn't allow API key creation. Choose an Anthropic Console account with /login and you'll be asked which method to use. Claude Code v2.1.242 or later is required. The (recommended) method stores an OAuth token as a profile and does not create an API key. The (legacy) method creates and stores an API key.

In the following cases, no choice is offered and an API key is created.

  • If you run it on a cloud provider
  • When the settings file has forceLoginOrgUUID, or forceLoginMethod is "claudeai" or "console"
  • When a managed settings source exists but Claude Code can't read it, and no other source provides a policy

Before signing in without a key, unset ANTHROPIC_API_KEY. Signing in this way signs you out of the claude.ai login on that machine. To undo it, use /logout.

Restrict sign-in to your organization

Setting forceLoginMethod and forceLoginOrgUUID in managed settings restricts claude.ai login to a specific organization. Put the organization ID in forceLoginOrgUUID. The example from the official docs is below.

{
  "forceLoginMethod": "claudeai",
  "forceLoginOrgUUID": ["xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"],
  "allowedProviders": ["anthropic", "bedrock"]
}

In this example, allowedProviders (Claude Code v2.1.285 or later) lists the services that connections are allowed to. Settings for developers signed in to a claude.ai organization or for Bedrock can start, and any other provider is rejected.

Keep the following points in mind.

  • The /login and first-run onboarding screens only preselect the method; they don't enforce it. Even if you specify "claudeai", you can still complete a Console login.
  • claude setup-token and /install-github-app enforce only forceLoginMethod, and they can create tokens for a different organization.
  • Server-managed settings only reach authenticated accounts, and you can't guide the first login. Distribute settings with a device management tool, and if you use both, put the same keys in each.
  • Credentials in environment variables such as ANTHROPIC_API_KEY are blocked at startup when you set these keys.

FAQ

What should I do if the browser doesn't open, or a login code is displayed?

Press c to copy the login URL and paste it into your browser. If a code is shown, paste it at Paste code here if prompted in the terminal. The official docs say this is more likely to happen in WSL2, SSH sessions, and containers.

Source: Authentication

Which authentication method is recommended for teams?

The official docs recommend Claude for Teams or Enterprise for most teams. Organizations that want API-based billing choose Claude Console, and organizations that use a cloud provider choose that provider's setup.

Source: Authentication

Can I sign in to the Console without creating an API key?

Yes. If you choose a Console account with /login, you are asked which method to use (Claude Code v2.1.242 or later). However, an API key is created in some cases, such as when using a cloud provider or when forceLoginOrgUUID is set.
