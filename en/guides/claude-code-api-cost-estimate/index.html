How to estimate costs when using Claude Code with the API (how tokens are counted and unit prices)

Published: October 14, 2026 ・ Chuki DX Lab ・ Unit prices are the values I checked on the official pricing page as of 2026-10-14

Key takeaways

  • API cost is calculated as "number of tokens × price per million tokens," summed across each type: input, cache write, cache read, and output.
  • Claude Code sends the conversation history every time, so cache-read token counts tend to be large. This is where it differs from estimates for ordinary chat.
  • A price list alone doesn't determine a department's monthly cost. As the official docs advise, try it with a small group, measure the actual token usage, and then make your estimate.

What is a token?

A token is the unit an AI model uses to process text. API (the interface for using Claude from a program) pricing is based on the number of tokens, not characters. The same applies when you use Claude Code (the AI coding agent from Anthropic that runs in the terminal) with pay-as-you-go API billing. Behind a single request, it exchanges messages with the model many times, and tokens are counted each time.

The estimate distinguishes four types of tokens (five if you split cache writes into 5-minute and 1-hour).

  • Input: the part of what you sent to the model that did not use the cache
  • Cache write: the portion of what you sent that is stored in the cache for reuse in the next request. There are two retention periods, 5 minutes and 1 hour, with different unit prices
  • Cache reads: The portion that reuses content already stored. The unit price is far lower than for input.
  • Output: What the model returns. The official docs state that thinking tokens are also billed as output.

Formula

The daily cost per person is calculated for each model with the following formula.

1日の金額(USD) = ( 入力 × 入力単価
                 + 5分キャッシュ書込 × その単価
                 + 1時間キャッシュ書込 × その単価
                 + キャッシュ読込 × その単価
                 + 出力 × 出力単価 ) ÷ 1,000,000

月額(USD) = 1日の金額 × 稼働日数 × 人数
月額(円)  = 月額(USD) × 為替レート

Because token volume and cost don't line up, it is important to calculate each type separately.

How to check token counts

The accuracy of your estimate depends on how closely you can bring the daily token count in line with actual usage. The official docs as of writing describe the following approaches.

  • /usage command: shows the current session's token counts by type. The dollar amount shown is an estimate calculated from the token counts at list price; the official docs say to confirm the authoritative billing figure on the Claude Console usage page.
  • Claude Console usage page: If you use the API under a contract, these are the numbers your billing is based on.

Claude Code also stores conversation records on your PC (under .claude in your user folder), and those records contain token counts too. However, the records are deleted after 30 days by default, so if you want to measure usage, decide on a period and tally it early.

The official docs also give average figures for enterprise use: about 13 USD per developer per active day, 150 to 250 USD per month, and 90% of users under 30 USD per day. They also say to establish a baseline with a small pilot group before expanding. I recommend treating the averages as a rough guide and measuring your own usage.

Differences from subscription plans

If you use Claude Code through a subscription such as Pro, Max, or Team, its usage is included in the monthly fee. The official docs explain that for Pro and Max users, the session dollar amount shown by /usage is unrelated to billing. In that case, treat the API-equivalent amount as a yardstick for comparing who is using how much, and use it as input when thinking about plan allocations.

Ways to keep costs down

  • Use different models for different work: The official docs say Sonnet can handle most coding tasks and costs less than Opus, and recommend saving Opus for things like complex design decisions.
  • Use /clear when you move to unrelated work: the longer the history, the more is sent with every request.
  • Adjust effort (reasoning depth): The official docs say that for simple tasks that don't need deep reasoning, lowering effort with /effort can reduce cost.

FAQ

Is the amount shown in /usage the same as my bill?

The official docs describe these as estimates. To confirm the exact API billing amount, check the usage page in the Claude Console. For subscriptions, this is unrelated to billing.

How do I get amounts in yen?

Pricing is set in USD. Multiply by the exchange rate on the day of the estimate to get yen, and note the rate and date you used in the document.

How many tokens does a subscription usage allowance cover?

In the official pricing page as of writing, plan usage allowances are expressed in relative terms such as "X times Pro," not in token counts.

Calculate your monthly cost in the browser

In the Claude Code API Cost Calculator, enter the number of users, tokens per day, working days, and model to calculate the monthly cost in USD and yen using this article's formula. You can also load the numbers from the example above.
