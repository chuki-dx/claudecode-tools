Claude Code Terms of Service and Compliance: Terms by Plan and What to Check

Published: October 15, 2026 · Chuki DX Lab · The content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section.

Key takeaways

  • For Claude Code (Anthropic's AI coding agent that runs in the terminal), Team, Enterprise, and Claude API plans fall under the Commercial Terms, while Free, Pro, and Max plans fall under the consumer terms.
  • If you embed it in your own products or services, conditions apply, such as no modifying the binary and no absorbing usage fees or reselling.
  • For points that are hard to judge, such as authentication methods or a medical BAA, check the official docs and contact sales if needed.

Terms of use differ by plan

According to the official docs, use of Claude Code is subject to the following terms.

  • Commercial Terms of Service: applies to users of Team, Enterprise, and the Claude API
  • Consumer Terms of Service: applies to Free, Pro, and Max users

Whether you use the Claude API directly or go through Amazon Bedrock or Google Cloud's Agent Platform, your existing commercial agreement also applies to Claude Code unless you have a separate agreement.

This content is based on the official docs as of writing (October 2026). Check the latest version of the terms before adopting.

Source: Legal and compliance

Conditions for embedding it in your own products or services

According to the official docs, if you preinstall Claude Code in your own product or service, or run it on an agent platform such as a hosted sandbox, you must agree to the Commercial Terms and comply with the following conditions, unless you have a separate agreement.

  • Do not modify the Claude Code binary. Install and run it exactly as Anthropic publishes it. You also cannot remove, disable, or restrict the authentication methods, including signing in with a Claude account or with the user's own API key.
  • You cannot pay for Claude usage on behalf of your users, resell it, or act as an intermediary. Each user authenticates with their own API key, Claude subscription credentials, or credentials for a third-party inference provider (Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry), and usage is billed directly under that user's own agreement.

Use of the name and logo

You may state, in plain text and accurately, that Claude Code is preinstalled on your product or that your product runs Claude Code. However, you may not use the names or logos of Claude Code or Anthropic as your product name, feature name, company name, or logo, or use them in a way that suggests Anthropic developed, approved, or partnered with you. Any other use is subject to the trademark guidelines and requires written permission.

Source: Legal and compliance

Authentication and credentials: when to use OAuth vs. an API key

Claude Code authenticates with an OAuth token or an API key. The official docs separate the two by purpose.

  • OAuth authentication is for Claude Free, Pro, Max, Team, and Enterprise subscribers, and is intended for ordinary use of Anthropic's native apps such as Claude Code.
  • If you're a developer building a product or service that uses Claude's capabilities (including use of the Agent SDK), use API key authentication through Claude Console or a supported cloud provider.

Third-party developers may not offer Claude.ai login in their own apps, or route user requests using Free, Pro, or Max credentials. You also may not collect, store, or proxy Claude.ai credentials or session tokens.

What is not restricted

The docs state explicitly that the following two are not restricted.

  • Setting API keys in development environments, secret management tools, machine images, and similar, and letting users your company has authorized use them. The conditions are that usage charges are billed to the key owner and that this does not amount to resale or brokering.
  • The user signs in to an unmodified Claude Code with their own Claude subscription.

Anthropic may take action to enforce these restrictions without prior notice. If you're unsure about a use case, you are directed to contact sales.

Source: Legal and compliance

Healthcare compliance (BAA)

According to the official docs, if a customer has signed a Business Associate Agreement (BAA) with Anthropic, the BAA covers Claude Code in the following two configurations. Which one applies depends on what is available to your organization.

  • HIPAA configuration: This setup uses the Claude Code CLI or the Code tab in Claude Desktop with a Claude for Enterprise account. Your organization must enable HIPAA and apply the HIPAA configuration to Claude Code (local mode) and Cowork (local mode).
  • Zero Data Retention (ZDR): Claude Code in an organization where ZDR is enabled. ZDR is not available to every organization.

HIPAA configurations do not cover cloud sessions, Remote Control, Claude Code in the Claude mobile app, or Claude Code through third-party cloud providers or gateways. Check the Implementation Guide it points to for the full list of covered services. This page does not explain HIPAA or BAA terms themselves, so if they may apply to you, confirm with the official docs and your contract contact.

Source: Legal and compliance

Usage policy, contact points, and checks before trying it internally

Using Claude Code is subject to the Anthropic Usage Policy. The usage limits described for the Pro and Max plans assume ordinary individual use of Claude Code and the Agent SDK.

The docs point to the Anthropic Trust Center and Transparency Hub, and vulnerabilities are reported through the HackerOne reporting form.

Checks before trying it internally

  1. Check your current plan and the terms that apply
  2. If you plan to embed it in your company's products or services, check it against the no-modification and billing terms
  3. Check that the authentication method you require users to use (OAuth or API key) fits your use case
  4. If you may handle medical information, check whether your setup is covered by a BAA

Source: Legal and compliance

FAQ

Which terms apply when I use it on a Team plan?

According to the official docs, the Commercial Terms of Service apply to Team, Enterprise, and Claude API users. Free, Pro, and Max users are covered by the Consumer Terms of Service.

Source: Legal and compliance

Can I build Claude Code into my own service and have the company cover the usage fees centrally?

No, unless there is a separate agreement. Per the official docs, paying for usage on behalf of end users, reselling, or acting as an intermediary is not permitted. Each user authenticates with their own credentials, and usage is billed directly to that user. For your specific situation, contact the sales team.

Source: Legal and compliance

Is it a problem to set an API key in a shared internal environment and have people use it?

The official docs say that setting an API key in development environments, secrets management tools, or machine images and letting your company's authorized users use it is not restricted. However, the usage charges must be billed to the key's owner, and it must not amount to resale or brokering.

Source: Legal and compliance
