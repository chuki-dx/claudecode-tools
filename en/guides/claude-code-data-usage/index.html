Is Claude Code conversation data used for training? Retention periods and where to check settings

Published: October 15, 2026 · Chuki DX Lab · The content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section.

Key takeaways

  • On individual plans (Free, Pro, Max), there is a setting that lets you choose whether your data is used to improve future models. While it is on, your Claude Code (an AI coding agent from Anthropic that runs in the terminal) usage is also used for training.
  • On commercial plans (Team, Enterprise, API, and so on), code and prompts sent under commercial terms are not used to train generative models, unless the customer chooses to provide them for model improvement.
  • Retention is 5 years for individual accounts that opt in, 30 days for individual accounts that do not, and 30 days as the standard for commercial plans. Zero data retention is enabled separately for eligible Enterprise accounts and is not included by default.

Whether your data is used for training depends on your plan

This article summarizes the official docs page "Data usage" as of writing (October 2026). It is not based on testing on a real machine.

Individual plans (Free, Pro, Max)

According to the official docs, users of Free, Pro, and Max accounts can choose whether their data may be used to improve future Claude models. When this setting is on, data from using Claude Code with those accounts is also used to train new models.

Commercial (Team, Enterprise, API, etc.)

Team and Enterprise, the API, third-party platforms, and Claude Gov are treated as commercial. The official docs state that under commercial terms, Anthropic does not train generative models on code or prompts sent to Claude Code. The exception is when the customer themselves chooses to provide data for model improvement.

One exception is the Development Partner Program. An organization admin must explicitly opt in, and it applies only to the Anthropic API directly. Users of Amazon Bedrock or Google Cloud's Agent Platform are not covered.

Source: Data usage

Retention period: 5 years or 30 days for consumer plans, 30 days standard for commercial

According to the official docs, Anthropic stores Claude Code data depending on the account type and settings.

Individual plans (Free, Pro, Max)

  • If you have allowed use for model improvement: 5 years (for model development and safety improvements)
  • If you haven't allowed it: 30 days
  • You can change your privacy settings at any time.

Commercial (Team, Enterprise, API)

  • Standard: 30 days
  • Zero data retention: Available for Claude Code on Claude for Enterprise, for eligible accounts. It is not included in the standard Enterprise plan; it is enabled per organization after your account team confirms eligibility.
  • Local cache: The Claude Code client stores session transcripts in plain text in ~/.claude/projects/, for 30 days by default. This is for resuming sessions, and you can adjust the period with cleanupPeriodDays. Transcripts of sessions started or most recently continued in Claude Desktop or Cowork are, by default, not subject to this expiry.

You can delete cloud sessions individually at any time, and deleting one permanently removes the session's event data. The fact that data stays locally in plain text is something to consider when setting your device management policy.

Source: Data usage

Where to check settings, and the order to check them in-house

You can change the personal privacy settings at any time on the settings page linked from the official docs. For detailed terms, the docs direct you to the Commercial Terms of Service (Team, Enterprise, API), the Consumer Terms (Free, Pro, Max), the Privacy Policy, and the Privacy Center.

  1. Check the plan of the account you will use (individual or commercial).
  2. For personal plans, check the setting for use of your data for model improvement.
  3. For commercial use, ask your administrator whether your organization participates in the Development Partner Program.
  4. If you need zero data retention, ask your account team about eligibility.

Data sent through feedback and surveys

Separate from the training settings, some data is sent depending on user actions and configuration.

  • /feedback: Sends a copy of your conversation history (including code) to Anthropic. However, if you use a third-party provider such as Amazon Bedrock or Google Cloud's Agent Platform, or have no Anthropic credentials configured, it is not sent to Anthropic and is instead written locally as an archive to ~/.claude/feedback-bundles/. /bug and /share use the same path, and records shared through them are retained for 5 years. Before sending, you can choose between the current session only (default) or also including the past 24 hours or 7 days of the same project. To disable it, set DISABLE_FEEDBACK_COMMAND=1.
  • Session quality survey: Only your rating is recorded. Only if you select "Yes" at the following prompt asking whether the session transcript may be viewed is the conversation transcript uploaded and kept for up to 6 months. (In sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or a signed-in Claude apps gateway, nothing is uploaded; it is written out as a local archive in ~/.claude/feedback-bundles/.) Known API key and token patterns are redacted, but source code and file contents are sent as-is. Your answers do not affect your training settings and are said not to be usable for model training. To disable it, set CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1.
  • Telemetry (usage metrics): latency, reliability, and usage patterns are sent; code, prompts, and file paths are not included. To turn it off, set DISABLE_TELEMETRY=1.

If you use Amazon Bedrock, Microsoft Foundry, or similar, telemetry, error reporting, and bug reporting are disabled by default, but the session quality survey is an exception and still runs. Setting CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC stops all nonessential traffic, including the survey.

Scope and caveats of zero data retention (ZDR)

According to the official docs, when ZDR is enabled, prompts and model responses generated in Claude Code sessions are processed in real time and are not stored by Anthropic after the response is returned. The exception is when storage is needed to comply with the law or to combat misuse.

  • This applies to eligible Claude for Enterprise accounts. It is not included in standard plans and cannot be enabled from the admin console. Contact your sales representative or your Anthropic account team.
  • Enabling is per organization. It is not applied automatically to a new organization created under the same account.
  • Only sessions logged in to a ZDR organization are covered. Usage with a personal account or an API key from a different organization is not covered. You can restrict login with the forceLoginMethod and forceLoginOrgUUID managed settings.
  • This applies only to Anthropic's direct platform. For Amazon Bedrock and others, check each platform's policy.
  • Not covered: claude.ai chat, Cowork, Claude Code Analytics, user and seat management data, and third-party integrations.
  • Features disabled automatically: cloud sessions, Claude Tag, Artifacts, /feedback, /bug, /share, and Remote Control.

For sessions flagged as policy violations, inputs and outputs may be retained for up to 2 years.

Source: Zero data retention

FAQ

If I use Claude Code on an individual Pro plan, are my conversations used for training?

If the setting that allows your data to be used for model improvement is on, your data, including Claude Code usage, is used to train new models. You can change this setting at any time on the privacy settings page linked from the official docs.

Source: Data usage

How long is data retained if I don't allow training?

For consumer plans, it is 30 days, or 5 years if you allow it. The standard for commercial plans is 30 days, and zero data retention is enabled separately for eligible Enterprise accounts.

Source: Data usage

If we sign up for an Enterprise plan, can we use zero data retention?

It is not available by default. It is not included in the standard Enterprise plan, and you cannot enable it from the admin console. After an eligibility check, Anthropic enables it for each organization.

Source: Zero data retention
