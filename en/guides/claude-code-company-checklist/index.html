What to check before trying Claude Code at your company (plan, PC, network, company rules)

Published: October 14, 2026 ・ Chuki DX Lab ・ Content is based on the official docs as of writing (October 2026)

Key takeaways

  • Before installing, check these four things: your plan, your PC environment, your network, and company policies. Doing so reduces rework such as "it didn't work," "it couldn't connect," or "it violated company rules."
  • Claude Code is not available on the free plan. On Windows you can install it without administrator rights, but check your company's installation procedures separately.
  • If your company rules do not mention AI tools, decide the scope in which you will use them, consult your manager or the person in charge once, and keep a record of it.

Why check first

When you try Claude Code (an AI coding agent from Anthropic that runs in the terminal) inside a company, most blockers aren't technical difficulty. They are things you could have checked in advance: the plan you signed up for didn't support it, the corporate proxy blocked the traffic, or it turned out later to conflict with company policy.

For a tool you use personally, just trying it out is fine. But with AI tools used for work, if a problem turns up later, people tend to ask why you used it without checking. If you check first, you can tell your manager, "I've confirmed the plan, environment, and rules."

Below is a checklist based on the official docs as of writing (October 2026). Product specifications change, so check the latest information at the linked pages right before you try it.

1. Check your plan (account)

  • Do you have a plan that includes Claude Code?: The official docs say you need a Pro, Max, Team, or Enterprise plan, or a Console (the admin site for the API) account. The free claude.ai plan doesn't include Claude Code.
  • Individual or organizational subscription: Decide whether to start small with an individual Pro plan or go straight to an organizational plan such as Team. Organizational plans include admin features, and data handling differs from individual plans.
  • Is your country or region supported? You must use it in a country or region where Anthropic provides the service.

Whether you may handle business data under a personal subscription depends on the company. If you're unsure, complete the "Checking internal rules" section later in this article first and then choose a plan, so you avoid rework.

2. Check your PC environment

For corporate IT at small and midsize companies, the big advantage is that you can install it without administrator privileges. However, not needing privileges is a separate question from whether installing it is allowed internally. I cover that in the section on internal rules.

If you want to align update timing across the company, decide how to update from the trial stage. This prevents versions from varying from user to user.

3. Check the network

Claude Code requires an internet connection. If your company has a proxy or firewall, you may need to allow certain destinations. The official docs list the following as destinations that need to be allowed (partial list).

  • api.anthropic.com (the Claude API)
  • claude.ai and claude.com (for signing in with a claude.ai account)
  • platform.claude.com (for example, signing in with a Console account)
  • downloads.claude.ai (installation and auto-updates)

If you go through a proxy, the docs describe setting the HTTPS_PROXY environment variable to the proxy's URL. The list of destinations can change, so check the latest table in the official docs before requesting an allowlist.

If you leave UTM (unified threat management) appliance or proxy settings to an outside vendor, it can take several days for an allow rule to take effect. If you've already picked a day to try this, it's safer to start on this item early.

4. Check internal rules

This is not about product specifications but about checking your own company's rules. Sometimes corporate IT is the one who writes the rules, and sometimes it is the one who checks with general affairs or the person in charge of information management.

  • Whether your information security policy permits the use of external AI services
  • What information may be entered into the AI: for example, a line such as "work procedures are fine, but customer names and personal information are not"
  • How conversation data is handled: The official docs explain that on individual plans (Free, Pro, Max), users choose in settings whether their conversations are used to improve models, while under commercial terms such as Team, Enterprise, and API, data is generally not used for training. If you use it for work, check the settings before trying it.
  • Software installation procedures: Even if no admin rights are needed, your company may still require a request.
  • Who bears the cost: an individual paying out of pocket, or a department budget

Many companies have no mention of AI tools in their policies. In that case, don't assume "it isn't prohibited, so it's fine." I recommend talking once with your manager or the person in charge of information management about the scope you want to try. If you have a record of that conversation, you won't be stuck if you're asked to explain later.

5. Verifying after installation

  1. Run claude --version in a terminal and confirm that a version number is displayed.
  2. Run claude doctor to check for problems with the installation or settings files.
  3. Create an empty folder to experiment in, start claude inside it, and log in.

The third point looks minor, but it matters. Claude Code works inside the folder where you launch it. Don't launch it right away in a folder that holds important work files; starting from an empty folder is safer.

Once you have a folder to try things in, preparing two files first makes the rest of the work go more smoothly. One is CLAUDE.md, a file of instructions that Claude Code reads at startup. The other is .claude/settings.json, which defines the files it must not read and the commands it must not run. You can create drafts of both just by making selections in this site's CLAUDE.md Template Generator and Permissions (settings.json) Generator.

FAQ

Can I try a personal Pro plan first and move to a business plan later?

It is possible as an approach. However, whether you may handle business data under a personal contract depends on your company's rules. Limiting the scope of the trial to something like "fictional data only" and getting your manager's approval first will also make it easier to explain when you switch.

Can I install it on a PC without administrator rights?

The official docs state that installing on Windows does not require running as an administrator. However, if your company requires an application to install software, check that procedure first.

In an environment with a proxy, I can't get past the login screen

The destinations that need to be allowed may not be getting through. Check the destinations and proxy setup in the network configuration page of the official docs, and share the claude doctor output with the person in charge as well. That will speed things up.
