Using Claude Code in VS Code: how to install the extension and how it differs from the CLI

Published: October 15, 2026 · Chuki DX Lab · The content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section.

Key takeaways

  • According to the official docs, the VS Code extension lets you use Claude Code (the AI coding agent from Anthropic that runs in the terminal) in a graphical panel inside VS Code, and it is the recommended way to use Claude Code in VS Code.
  • The prerequisites are VS Code 1.94.0 or later and an Anthropic account. The extension includes the CLI (the command-line version), but to use claude in the integrated terminal you need to install the CLI separately.
  • Auto-edit permissions can also modify VS Code settings files, so when working with untrusted code, consider using Manual mode together with restricted mode.

What it can do and what you need

The following is based on the official docs I referenced as of writing (October 2026). With the extension, you can review and edit Claude's plan before accepting it, automatically accept edits, pass files with line numbers for the selected range using @-mentions (the syntax of adding @ to specify a file), open conversation history, and open multiple conversations in separate tabs or windows.

There are two prerequisites.

  • VS Code 1.94.0 or later
  • An Anthropic account. You can use a paid Claude subscription (Pro, Max, Team, Enterprise) or a Claude Console account, and no API key is needed. If you go through a third-party provider such as Amazon Bedrock, there is a separate setup procedure.

To install, press Ctrl+Shift+X (Cmd+Shift+X on Mac) in VS Code to open the Extensions view, search for "Claude Code," and click Install. If it doesn't appear, restart VS Code or run "Developer: Reload Window" from the Command Palette.

There is also a link for Cursor, and you can install it in other VS Code forks such as Devin Desktop and Kiro. For editors where you can't install the extension, the docs describe running the CLI claude in the integrated terminal.

Source: Use Claude Code in VS Code

From launch to your first request

The quickest way to open it is to click the Spark icon in the toolbar at the top right of the editor. It appears only while a file is open. The ✻ Claude Code item in the status bar works even when no file is open.

On first launch a sign-in screen appears, so click Sign in and authorize in your browser. If the sign-in screen appears even though you set ANTHROPIC_API_KEY in your shell, VS Code may not have inherited your shell's environment variables. Launch it from a terminal with code ., or sign in with your Claude account.

Selected text is automatically visible to Claude. Option+K (Alt+K on Windows/Linux) inserts a reference like @file.ts#5-10 into your prompt. You can specify files and folders by typing a name after @, and fuzzy matching is supported.

Explain the logic in @auth (fuzzy matches auth.js, AuthService.ts, etc.)

How file edits behave depends on the permission mode. In Manual mode, you see a side-by-side comparison of the original and the proposed change, and you can approve, reject, or give different instructions. The per-change Accept this change / Reject this change buttons require Claude Code v2.1.275 or later and don't appear for diffs with more than 100 changes, so review those file by file.

Permission modes and cautions for company use

You can switch the permission mode from the mode indicator below the prompt box.

  • Auto: A classifier reviews most actions in place of per-action prompts. In Claude Code v2.1.283 and later it is a built-in starting mode; before that, it is available only on Pro, Max, and Team plans.
  • Manual: Asks for permission before file edits and most shell commands.
  • Plan: Explains what it will do and waits for your approval. VS Code opens the plan as a Markdown document, and you can respond with inline comments before it runs.
  • Edit automatically: Edits without asking for confirmation.

The official docs warn that with auto-edit permissions, Claude Code can also modify files such as settings.json and tasks.json, which VS Code may run automatically. When working with untrusted code, the docs suggest enabling VS Code Restricted Mode, using Manual mode instead of Auto or Edit automatically, and reviewing changes carefully before approving them.

Excluding selected text also has conditions. For files inside the workspace that match files.exclude or search.exclude, at most the path is passed to Claude. However, this applies only to the chat panel; the CLI in the integrated terminal sends selected text regardless of the file. The docs advise adding a deny rule for Read to files you want to protect.

On the handling of code, the official docs state that Claude Code processes your code but does not use it to train models. For details, see the official Data and privacy page.

Source: Use Claude Code in VS Code

Differences from the CLI, and what to do when it doesn't work

Installing the extension does not add claude to your PATH. The extension bundles a copy of the CLI for the chat panel, so to run claude in the integrated terminal, install the standalone CLI separately.

  • Commands and skills: the CLI supports all of them; the extension supports a subset. The ! Bash shortcut and tab completion are CLI-only.
  • MCP (a mechanism for connecting Claude to external tools and APIs) server settings and checkpoints (a feature that records Claude's file edits so you can restore an earlier state) work in either case.

The extension and the CLI share the same conversation history, and you can continue an extension conversation from the CLI with claude --resume.

If you don't see the Spark icon, check that a file is open, that VS Code is version 1.94.0 or later, and that no other AI extension conflicts with it. The extension doesn't run in Restricted Mode. Even if you uninstall the extension, running claude in the integrated terminal reinstalls it automatically, so to stop that, turn off Auto-install IDE extension in /config.

For settings or behavior not described here, check the official docs.

FAQ

Do I need an API key for the Claude Code VS Code extension?

The official docs say it is not required. You sign in with a paid Claude subscription (Pro, Max, Team, or Enterprise) or a Claude Console account.

Source: Use Claude Code in VS Code

I installed the extension, but claude isn't found in the terminal.

This is because the extension does not add claude to your PATH. To use it in the integrated terminal, you need to install the standalone CLI.

Source: Use Claude Code in VS Code

Can I continue a conversation started in the extension in the CLI?

The extension and the CLI share the same conversation history. Run claude --resume in the terminal to pick a conversation from the list and continue it.

Source: Use Claude Code in VS Code
