Claude Code Pricing and Plan Comparison: Differences Between Pro, Max, Team, Enterprise, and Console, and How to Choose

Published: October 17, 2026 ・ Chuki DX Lab ・ Content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section

Key takeaways

  • Pro and Max let you use Claude (web, desktop, and mobile) and Claude Code under a single subscription. They are an entry point for individuals or small groups to try it out.
  • SSO, server-managed settings, Code Review, and similar features are listed in the official docs' feature list as available on Team and above. Check the official pricing page for amounts.
  • Your plan's usage allowance and Console API credits are billed separately. If ANTHROPIC_API_KEY is set, usage is billed to the API, so check this first.

What you can do with Claude Code (Pro and Max)

Claude Code is an AI coding agent from Anthropic that runs in the terminal. According to the official Help Center, it is a tool that lets you use Claude models directly from the terminal or a supported IDE, so you can delegate complex coding work while keeping transparency and control. With Pro and Max, one subscription covers both Claude (web, desktop, and mobile) and Claude Code in the terminal.

Supported IDEs are VS Code, VS Code derivatives such as Cursor, and JetBrains IDEs such as IntelliJ and PyCharm. You sign in with the same credentials as the terminal, and IDE usage counts toward the same usage limit shared by Claude and Claude Code.

This article is based on sources as of writing (October 2026). The sources do not include amounts or usage limit figures, so check the official pricing page for the latest information.

Source: Use Claude Code with your Pro or Max plan

Getting started with Pro and Max: settings and caveats

  1. Confirm that your Pro or Max subscription is active
  2. Follow the Claude Code page in the official docs and install it for your OS
  3. Sign in with the same credentials as Claude during setup or on first use

If you are already logged in with Claude Console pay-as-you-go (PAYG) billing, run /login inside Claude Code to switch to a subscription.

When authentication options don't appear

  1. Log out completely with /logout
  2. Run claude update
  3. Fully restart the terminal
  4. Run claude and choose the correct account

Note: If an ANTHROPIC_API_KEY environment variable exists on the system, Claude Code authenticates with this API key instead of a subscription (Pro, Max, Team, Enterprise). As a result, you incur API usage charges rather than using the allowance included in your plan. Before trying it on a company machine, it's wise to check whether this variable is set.

Source: Use Claude Code with your Pro or Max plan

How billing works: plan allowances and API credits are separate

The official Help Center describes Claude Code and the Claude Console / Claude API as separate systems. Claude Code offers the option of continuing with API credits, and the auto-reload setting is on the Console side.

  • If you choose API credits, you are billed at standard API rates (separate from the Pro/Max plan fee)
  • If auto-reload is enabled in the Console, credits are added automatically when your balance runs low
  • auto-reload works only if you chose to use API credits

How to stay within your plan's limits

  • Decline the API credit option if it appears
  • Wait for the usage period to reset
  • Check your remaining quota with the /status command

How to stop it from offering choices

  1. Run claude logout in your terminal
  2. Run claude login and authenticate with Pro or Max credentials only
  3. Don't add Claude Console credentials while logging in

With this setup, when you hit the limit you are reportedly not prompted to use API credits and only the plan's allowance is used. Check and adjust the auto-reload status in the Billing settings in the Console.

Source: Use Claude Code with your Pro or Max plan

Using it with Team and Enterprise

According to the official Help Center, on the new Enterprise plan or the self-serve Enterprise plan, Claude Code is included in every Enterprise seat and no additional purchase is needed. On older Enterprise plans (Chat and Chat + Claude Code seats, or Standard and Premium seats), you need a seat type that includes Claude Code. Owners can purchase and reassign Chat + Claude Code / Premium seats under Organization settings > Organization.

Take care with HIPAA-ready Enterprise plans. If the primary owner has not applied the HIPAA configuration and Claude Code does not have zero data retention (ZDR), Claude Code is included in the seat and usable, but it is not covered by the BAA. You are advised not to use it with protected health information (PHI).

Sign-in flow

  1. Type claude in the terminal to start a session
  2. Choose a login method (if you're already logged in with a different account, run /login)
  3. Select "Claude account with subscription" and proceed to the OAuth screen
  4. Select a Team or Enterprise plan and click "Authorize"

After you log in, the skills and plugins on your Claude account, including those provided by your organization, are loaded into Claude Code automatically. This requires Claude Code v2.1.273 or later. The steps for when no authentication options appear are the same as those given for Pro and Max.

Feature differences by plan and a rough guide to choosing one

According to the official docs, when you sign in with a claude.ai account, the features available depend on your plan. This distinction does not apply when you authenticate with Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or an Anthropic Console API key. Applying the HIPAA configuration on Enterprise disables some features.

  • Pro and Max only: Computer use, Dispatch (Desktop)
  • Team and Enterprise only: Code Review, analytics dashboard and contribution metrics, Server-managed settings, SSO
  • Enterprise only: Enterprise Analytics API, SCIM, Compliance API, Zero Data Retention
  • Remote Control and Channels: available on Pro and Max; on Team and Enterprise, only if an admin has enabled them
  • Cloud sessions: Available on all plans. However, Enterprise requires a Premium seat or a Chat + Claude Code seat.

Zero Data Retention is not included in the standard Enterprise plan. Anthropic must enable it separately for accounts that meet the conditions. For a detailed comparison including pricing, see the official Team and Enterprise plan pages.

How to choose

  • Trying it solo or with a small team: Pro or Max (Computer use and other features are available)
  • You need SSO, server-managed settings, or usage analytics: Team or higher
  • If you need SCIM, the Compliance API, or zero data retention: Enterprise (zero data retention must be enabled separately)

FAQ

If I set ANTHROPIC_API_KEY, will my Pro or Max allowance go unused?

According to the official Help Center, when this environment variable is set, Claude Code authenticates with an API key instead of a subscription. As a result, you are charged API usage fees rather than using the allowance included in your plan.

Source: Use Claude Code with your Pro or Max plan

Do I need to purchase Claude Code separately on an Enterprise plan?

On new Enterprise plans and self-serve Enterprise plans, it is included with every Enterprise seat and requires no additional purchase. On older plans, you need a seat type that includes Claude Code.

Source: Use Claude Code with your Team or Enterprise plan

Can I use Computer use on the Team plan?

In the official docs' feature list, Computer use is available on Pro and Max and unavailable on Team and Enterprise. Code Review is the opposite: Team and Enterprise only.
