Export Claude Code per-user costs as CSV: spend reports for Team and Enterprise, and for API and cloud setups

Published: November 26, 2026 | Chuki DX Lab | Content is based on sources such as the official docs as of writing (November 2026); sources are listed at the end of each section

Key takeaways

  • The spend report in the Team and Enterprise analytics screen can be exported as a CSV by user and by model (updated daily). However, it covers only spend on usage credits and does not include usage within seat allowances.
  • The spend report can be viewed by Owners and Primary Owners on Team, and by Owners and Primary Owners on Enterprise. Enterprise Admins can view analytics other than Spend.
  • API usage (Console) and usage through cloud providers are checked in different places. Cloud usage is outside the analytics screen, so aggregate it yourself with OpenTelemetry or similar.

Where to see per-user numbers depends on your contract type

Where you view per-user usage and cost for Claude Code (Anthropic's AI coding agent that runs in the terminal) depends on how your organization uses it. According to the official docs, there are three types: Claude for Teams and Enterprise, Claude Console (API), and cloud providers (Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry).

On Teams and Enterprise, usage is deducted from each member's seat allowance. On Console and cloud providers, the organization is billed per token. If people sign in in different ways, usage is measured by the method each developer used to authenticate.

  • Teams and Enterprise: the spend report in the organization's analytics screen (CSV export available). Enterprise also has the Enterprise Analytics API.
  • Console (API): the Console dashboard and the Claude Code Analytics API
  • Via cloud providers: OpenTelemetry or an LLM gateway

OpenTelemetry works with every setup and is described as the only option that can stream per-user token and cost data to your own monitoring stack in near real time. This guide is based on the official docs and Help Center as of writing (November 2026). Screen and button names may change, so check them on your actual screen.

Team and Enterprise: how to export the spend report as CSV

According to the official Help Center, usage analytics are available to the Owner and Primary Owner on Team plans, and to the Owner, Primary Owner, and Admin on Enterprise plans. However, Enterprise Admins can see only the analytics other than Spend.

The spend report is a CSV that shows token usage and estimated spend by user and by model for the period you select. Here is how to export it.

  1. Open Settings > Analytics.
  2. Scroll to the How much is Claude costing? section.
  3. Click the "Export spend report" button.
  4. Choose a period from MTD, Last Month, Last 90 Days, or Custom.
  5. For Custom, choose a start date and an end date. You can go back up to 90 days, and the most recent data is from the previous day.
  6. Click "Download".

Source: View usage analytics for Team and Enterprise plans

What the CSV contains, what it excludes, and how often it updates

According to the official Help Center, each CSV row is one specific person's usage of one specific model, and spend is totaled across the entire selected period. The columns are as follows.

  • User email address
  • Account UUID
  • Product (Chat, Claude Code, Cowork, Office Agents, and more)
  • Model and model family
  • total_requests: Number of API calls
  • total_prompt_tokens: Number of tokens consumed on the input side of each request
  • total_completion_tokens: The number of tokens Claude generated (including extended thinking tokens)
  • total_net_spend_usd: Cost (USD) after discounts, credits, and negotiated rates are applied
  • total_gross_spend_usd: Cost in USD before discounts or credits are applied

Usage within the seat allowance is not included

On seat-based Enterprise plans, the spend data covers only spend beyond the seat allowance. On seat-based Enterprise plans, the spend report appears only if the organization has enabled usage credits, and it does not include usage within the seat allowance. On usage-based Enterprise plans, all of the organization's usage is included. The official Claude Code docs also explain that usage within the seat allowance is not measured in dollars.

Update frequency and how it relates to billing

Data is updated daily, with a one-day delay. The Help Center says an exported spend report should roughly match your invoice, but spend grouped by project tag may not match. Also, some items that used to be bundled under Claude Code, such as Code Review and security features, now appear as separate line items.

Source: View usage analytics for Team and Enterprise plans

The Enterprise Analytics API and other CSV exports from the dashboard

According to the official docs, on the Enterprise plan the Enterprise Analytics API returns per-user usage and cost reports for Claude services, including Claude Code. It is not available on the Teams plan, so for Teams, use the spend report CSV described in the previous section.

The Primary Owner creates the key with the read:analytics scope. According to the Help Center, only the Primary Owner can enable the Analytics API and create keys, and it isn't shown in the settings screen at all for Owners or Admins. This is expected behavior, not a permissions error.

The Claude Code analytics dashboard also has a CSV export. "Export all users" in the Leaderboard outputs contribution data for all users (PRs and lines of code), but this is not a cost CSV. Check costs in the spend report.

Where to check for Console (API) and cloud setups

For Console (API)

According to the official docs, the Claude Code dashboard in the Console shows spend and accepted lines per member. Viewing it requires the UsageView permission, which the Developer, Billing, Admin, Owner, and Primary Owner roles have. By default, the team insights table shows Members, Spend, and Lines accepted for the last 30 days. The amounts are estimates for analysis; check the Cost page for actual charges.

To pull daily per-user metrics programmatically, call the Claude Code Analytics API with an Admin API key. The source does not mention CSV export from the dashboard, so check the official docs.

Via cloud providers

With Amazon Bedrock and similar setups, Claude Code does not send cloud-side metrics to Anthropic, so they are not covered by the analytics dashboard or the Claude Code Analytics API. There are three options for aggregating by user.

  • OpenTelemetry: Export from each developer's machine to your own monitoring platform to get per-user token counts, costs, and tool activity.
  • Claude apps gateway: You run it yourself, and it provides per-user usage attribution, OTLP metrics, and per-user spend limits.
  • LLM gateway: Routes all traffic through a proxy and tracks spend per key. The example, LiteLLM, is open source, is not affiliated with Anthropic, and is stated to have not been security audited.

FAQ

Can an Enterprise Admin export the spend report as CSV?

According to the official Help Center, an Enterprise Admin can view analytics other than Spend. To check spend, ask an Owner or the Primary Owner.

Source: View usage analytics for Team and Enterprise plans

Does the CSV include usage within seat allowances?

No. On seat-based Enterprise plans, if you enable usage credits, only spend beyond the seat allowance is reflected.

Source: View usage analytics for Team and Enterprise plans

Can I see per-user cost when using a cloud provider such as Bedrock?

These are outside the analytics dashboard. The official docs list three methods: OpenTelemetry, Claude apps gateway, and LLM gateway.
