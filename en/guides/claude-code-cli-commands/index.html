Claude Code CLI commands: when to use claude, claude -p, and claude update

Published: October 24, 2026 ・ Chuki DX Lab ・ Content is based on the official docs and other sources as of writing (October 2026); sources are listed at the end of each section

Key takeaways

  • There are three everyday entry points: claude to start an interactive session, claude -p "query" to send one query and exit, and claude -c to continue the most recent conversation.
  • To update, use claude update. To install or reinstall a specific version, use claude install [version]. To check the installation's status, use the read-only claude doctor.
  • claude mcp, the background session commands, claude purge, and similar commands depend on version or environment conditions, and some involve deletion, so check the official docs before you distribute them company-wide.

Basic commands for starting, asking questions, and resuming

This guide is based on the command table in the CLI reference of the official docs. According to the official docs, Claude Code (an AI coding agent from Anthropic that runs in the terminal) uses commands starting with claude to start sessions, pipe in content, resume conversations, and manage updates. It is based on the table as of writing (October 2026), so check the official docs for the latest information.

Start interactively

  • claude: starts an interactive session.
  • claude "query": starts an interactive session with an initial prompt. For example: claude "explain this project".

Finish in one go

claude -p "query" sends a query through the SDK and then exits. The example is claude -p "explain this function". The table also lists piping file contents in for processing; the example passes a log file and asks Claude to explain it.

Resume from where you left off

  • claude -c: Continues the most recent conversation in the current directory.
  • claude -c -p "query": Continues via the SDK. For example: claude -c -p "Check for type errors".
  • claude -r "<session>" "query": Resumes a session by ID or name. For example: claude -r "auth-refactor" "Finish this PR".

Source: CLI reference

Commands for updating, installing, and diagnostics

claude update updates to the latest version. claude install [version] installs or reinstalls the native binary, and accepts a version such as 2.1.118, as well as stable or latest. An example is claude install stable. For details, see the Install a specific version section of the official docs.

claude doctor shows, read-only and without starting a session, the installation status, settings file validation errors, Remote Control eligibility, and more. The in-session check that can also apply fixes is /doctor.

If you mistype a subcommand, Claude Code suggests the closest match and exits without starting a session. For example, claude udpate prints Did you mean claude update?.

Source: CLI reference

Authentication-related commands

  • claude auth login: Signs in to your Anthropic account. Use --email to prefill the email address and --sso to force SSO authentication. With --console, you sign in through the Anthropic Console with usage-based API billing instead of a Claude subscription.
  • claude auth logout: logs you out of your Anthropic account.
  • claude auth status: Shows the authentication status as JSON. Use --text for a human-readable format. It exits with code 0 when logged in and 1 when not logged in.

authMethod in the JSON from claude auth status is one of none, claude.ai, oauth_token, api_key, api_key_helper, or third_party. The configDirectory field, which shows the config directory, requires Claude Code v2.1.268 or later.

claude setup-token generates a long-lived OAuth token for CI and scripts. The token is only displayed in the terminal and is not saved, and a Claude subscription is required. Be careful how you handle any copy of the displayed value.

Source: CLI reference

MCP and plugin commands

claude mcp is the command for configuring Model Context Protocol (MCP) servers. For usage details, see the MCP page in the official docs.

  • claude mcp login <name>: runs the OAuth flow (the authentication procedure) for a configured MCP server without opening the interactive /mcp panel. It works with HTTP, SSE, and claude.ai connector servers. Over SSH, add --no-browser to print the authorization URL instead of opening a browser. Example: claude mcp login sentry.
  • claude mcp logout <name>: Clears the OAuth credentials stored for an MCP server. For example, claude mcp logout sentry.

claude plugin is the command for managing plugins, and its alias is claude plugins. An example is claude plugin install code-review@claude-plugins-official, and the subcommands are collected in the plugin reference in the official docs.

Source: CLI reference

Background sessions and commands that need attention

claude agents opens the agent view, where you monitor and assign parallel background sessions. It requires an interactive terminal. For individual operations, use claude attach 7c5dcf5d, claude logs 7c5dcf5d, claude stop 7c5dcf5d, claude respawn 7c5dcf5d, and claude rm 7c5dcf5d. They attach to a session, show recent output, stop it, restart it while keeping the conversation, and remove it from the list, respectively. Passing part of a name instead of an ID to attach and logs requires Claude Code v2.1.290 or later.

Commands that involve deletion

claude purge [path] deletes all local state for a project (transcripts, task lists, debug logs, file edit history, prompt history lines, and that project's entry in ~/.claude.json). Use --dry-run to preview, -y/--yes to skip confirmation, and --all to target all projects. An example is claude purge ~/work/repo --dry-run; it's safest to start with --dry-run.

Commands with environment conditions

claude import [source] imports settings from other coding agents, but it doesn't work with Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or Claude Platform on AWS, and it requires v2.1.213 or later. claude gateway is for administrators and requires --config. The --post option of claude ultrareview [target] targets github.com pull requests and requires v2.1.227 or later.

Source: CLI reference

FAQ

When should I use claude and when claude -p?

claude starts an interactive session, while claude -p "query" sends a query through the SDK and exits. In short: use the former to keep a conversation going, and the latter to finish with a single query. To continue where you left off, use claude -c or claude -c -p "query".

Source: CLI reference

What is the difference between claude update and claude install?

The official docs explain that claude update updates to the latest version, and claude install [version] installs or reinstalls the native binary; you can specify a version such as 2.1.118, stable, or latest. For steps to install a specific version, check the official docs.

Source: CLI reference

Can I check my login status with a command?

claude auth status shows the authentication state as JSON. Add --text for a human-readable format. It exits with code 0 when you're logged in and 1 when you're not.

Source: CLI reference
