How to estimate your monthly Claude Code cost

When you use Claude Code (Anthropic's AI coding agent that runs in the terminal) through the API, cost depends on the number of tokens (the unit AI uses to count text). Besides input and output, prompt cache writes and reads (a mechanism that reuses the same content to load it more cheaply) each have their own separate price. This calculator works out the cost per person per day with the formula below, then multiplies by working days and number of people.

API換算(USD) = ( 入力 × 入力単価
               + 5分キャッシュ書き込み × 5分キャッシュ書込単価
               + 1時間キャッシュ書き込み × 1時間キャッシュ書込単価
               + キャッシュ読み込み × キャッシュ読込単価
               + 出力 × 出力単価 ) ÷ 1,000,000

Claude Code sends the conversation history with every request, so cache-read tokens pile up the longer a session runs. Try entering example values and you'll see that read tokens are orders of magnitude higher than input tokens.

A number that is just the price list multiplied by headcount tends to drift from actual usage. Usage varies widely from person to person, so the official cost management page also recommends getting a baseline from a small pilot group before expanding (Manage costs effectively, as of writing). Have a few people use it for about two weeks, measure daily token counts, and then enter them in this calculator. You'll get figures you can use for internal approval (ringi) and budget explanations.

FAQ

How do I check the number of tokens per day?

If you are under an API contract, you can check usage on the usage page in Claude Console. If you have no admin console, such as during a trial period, the token counts remain in the conversation records Claude Code stores on your PC, so you can total them from there. The paid article below explains the tally script and the steps.

How much does it cost on the Pro, Max, and Team plans?

Subscriptions are billed monthly per seat, so they are outside the scope of this calculator. As of writing, I could not find how many tokens a plan's usage allowance corresponds to on the official pages. Check plan prices on the official pricing page.

Why is the default exchange rate empty?

Exchange rates change daily, so I left this field blank to avoid producing yen amounts from an outdated rate. Enter the rate for the day of your estimate. If you only want to see how the calculation works, you can use "Enter 150 as an example."

Are the numbers I enter sent anywhere?

No. Calculations happen only in your browser. To count page views, only the URL of the page you opened is sent to the operator's server (no cookies or external analytics services are used. Details).
