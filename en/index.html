ToolsFree tools

  • Claude Code Permissions (settings.json) Generator

    Choose policies such as "don't let it read .env," "don't let it send data out with curl or similar," and "ask before git push," and the tool outputs the matching deny / ask / allow rules for settings.json. It separates rules I confirmed actually block on a real machine from rules I did not verify individually.

  • CLAUDE.md Template Generator

    Choose the purpose, language, rules you want followed, and folders that must not be touched, and it outputs a CLAUDE.md template that Claude Code reads at startup. You can also switch to a minimal 3-line version, and it shows the line count so you can check that it stays within 200 lines.

  • Claude Code Skill (SKILL.md) Scaffold Generator

    Enter the skill name, description, when to use it, steps, and output format, and the tool outputs a scaffold for .claude/skills/<name>/SKILL.md. It checks how to write the skill name and the frontmatter format. Examples such as meeting-minutes summaries are included.

  • Claude Code Troubleshooting Cheat Sheet (for Windows and Corporate IT)

    Problems I hit on a real machine, such as allow not taking effect, rules being bypassed despite deny, garbled text in PowerShell, and CSV BOM issues, are organized into a table of symptom, cause, and fix. You can filter by keyword and category.

  • Claude Code API Cost Calculator

    Calculates the monthly cost in USD and yen for pay-as-you-go API usage, based on the number of users, tokens per day, working days, and model. Unit prices are the values I confirmed on the official page as of 2026-10-14.
